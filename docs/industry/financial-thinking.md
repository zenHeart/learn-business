# 资产负债与财商

> 商业世界的基础语法：把钱从口袋拿出去的是负债，往口袋放钱的是资产。个人和公司共用这套语法。（整理自《穷爸爸富爸爸》阅读笔记，2019）

## 资产与负债的朴素定义

- **资产**：无需你持续投入、能产生收入或有增值潜力且流动性好的东西
- **负债**：持续把钱从你口袋拿走的东西

典型的资产清单：

1. 无需本人管理的业务
2. 股票、债券、共同基金
3. 能产生收入的房地产
4. 票据
5. 版税（音乐、手稿、专利）
6. 其他有价值、可产生收入、有增值潜力且有销路的东西（收藏等）

> 容易误判的项：**自住房不是资产**（持续产生维护、税费支出且不产生收入）——这是本书最具争议也最有启发性的视角。争议在于它忽略了居住效用与杠杆属性；启发在于它强迫你区分"消费性持有"和"生产性持有"。

## 财商的四根柱子

| 维度 | 内容 |
|---|---|
| 财务知识 | 阅读理解数字的能力（报表、现金流） |
| 投资策略 | 以钱生钱的科学 |
| 市场 | 供给与需求 |
| 法律规章 | 在游戏规则之内创造财富 |

> 关键态度：**在游戏规则之内创造财富**——理解规则不是钻空子，是知道边界在哪。

## 投资者的两种类型

1. **一揽子投资者**：资产交给他人（基金等）打理
2. **创造性投资者**：自行组合投资策略

创造性投资者的三个能力：

- 信息不对称下**获取机会**的能力
- **增加资金**的手段
- **合理调配资源**，把精明的人组织起来

注意第三条——"组织精明的人"正是管理能力的资本化表述，与[工程师转管理](/management/eng-to-manager)是同一件事的两面。

## 已知局限（证伪）

- 本书方法论被批评为**幸存者偏差重、可操作性弱**：房地产套利叙事建立在美国特定时期的信贷环境上
- "现金流游戏"与部分理财话术被打包成高价课程销售，与原著立场背离
- 取其框架（资产负债二分法、财商四柱），不抄其具体投资建议——后者强烈依赖时代与环境

## 给自己的锚点

- 个人资产负债表盘点：列出手头所有物，逐项标注"月现金流方向"（流向你 + / 流向你 -）
- 每项"资产"问一句：它不需要我的时候还在产钱吗？（需要你全职投入的"生意"是工作不是资产）
- 财商四柱自评：哪根柱子最弱？下一本读物对着它选
