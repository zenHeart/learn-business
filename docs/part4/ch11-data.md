# ch11 一人公司的数据挖掘

> **本章目标**：建立"数据驱动但不数据崇拜"的思维——掌握一人公司必须监控的 8 个核心指标（MRR/CAC/LTV/NRR/留存/北极星/护栏/现金跑道）；建立仪表盘与归因思路；学会用 A/B 测试和漏斗分析找问题。这是整本书从"做"到"做得对"的环节。

## 真实场景

一个 SaaS 月入 $3k 增长到 $8k 后卡住。创始人盯着"流量涨得不错"的截图高兴，但翻到留存数据才发现：30 日留存从 35% 掉到 22%。**流量是表象，留存是病灶。** 没看到留存就投放，越投越亏。本章教你不再被表象迷惑。

## 三个核心区分

### 区分一：数据 ≠ 数字

数据是**有问题的数字**。"今天有 100 个访客"不是数据；"今天有 100 个访客，其中从 ch09 那个渠道来的 30 个、转化率比平均高 2 倍"才是数据——它能指导下一步。**问"这个数字能让我做什么不同的事吗"——答不上来，它就不是数据，是噪音。**

### 区分二：虚荣指标 vs 行动指标

虚荣指标看起来漂亮但不能指导行动（DAU/总注册数/总粉丝数）；行动指标丑但能用（最近 7 日激活率、北极星指标的周变化、付费用户 NPS）。**Adam Penenberg 的名言："几乎所有的互联网公司都死于虚荣指标。"**

### 区分三：数据驱动 ≠ 数据崇拜

数据是被验证的猜想的集合——它是工具不是真理。极端数据主义会在数据稀疏阶段（一人公司早期）制造**"分析瘫痪"**：没数据拍板不了。配比：**定性访谈（ch04）+ 合理信念 + 数据修正**，按阶段递进。

## 一人公司必监控的 8 个指标

按"决策价值"排序，从最重要开始：

### 1. 现金跑道（Runway）——比收入重要

```
现金跑道（月）= 当前现金 ÷ 月净流出
```

含义：按当前烧钱速度还能活几个月。**Binance/YC 的硬规则：6 个月以下跑道立刻进危机模式；12 个月以上才能正常决策**。一人公司把这个数字贴在显示器上——它决定你能"坚持"多久。

### 2. MRR（Monthly Recurring Revenue）——订阅制生意的命脉

```
MRR = 付费用户数 × 单用户月费
```

读 MRR 一定要**分解**：新增 MRR − 流失 MRR = 净新增 MRR。增长可能不是因为获取好，是因为流失少；停滞可能是获取不行也可能是流失加剧。看总 MRR 是失明的，看分解才有方向。

NRR（Net Revenue Retention）=（老用户本期付费 ÷ 老用户上期付费）× 100%。**NRR > 100% 意味着单凭老用户就能增长**，是 SaaS 最有质量的增长指标；优秀水平 ≥ 120%。

### 3. 北极星指标（North Star Metric）——对齐的唯一指标

ch10 提过：一个最能代表用户价值的指标，全团队（哪怕只有你一个人）用它对齐。选错的影响是结构性的——看后文"坑与证伪"。

### 4. 护栏指标（Guardrail Metric）——防止主指标被做坏

主指标变好常常伴随某种损坏（古德哈特定律：指标一旦成为目标就被博弈）。**每个主指标配一对护栏**：

| 主指标 | 护栏（变好但其他坏了的警报） |
|---|---|
| 7 日激活率 ↑ | 30 日留存（防假激活） |
| 付费转化率 ↑ | 退款率（防卖预期） |
| 内容点击率 ↑ | 退订率（防标题党） |
| 订单量 ↑ | 客单价 × 毛利率（防卖便宜货） |

### 5. 留存率——产品的真相

```
Day N 留存 = 第 N 天仍活跃/付费的用户 ÷ 当初新增用户
```

留存是产品真相（任何获取的增长都会被糟糕的留存吃掉——ch15 的 RARRA 体检）。三人公司的留存基准参考：Web SaaS Day 30 留存 **~20-40%**（产品好坏差距大），移动 App Day 1 **~40%**（行业经验）。**你自己的留存是多少，竞争对手的留存是多少，是你的产品定位是否成立的硬指标。**

### 6. CAC（Customer Acquisition Cost）——每获得一个付费用户花了多少

```
CAC = 一段时期的市场费用 ÷ 该时期获得的新付费用户数
```

注意：只算**市场费用**（不要把创始人工资、工具订阅算进去），否则会失真。CAC 必须配合 LTV 看，单独看意义有限。

### 7. LTV（LifeTime Value）——这个用户全程贡献多少收入

```
简化版 LTV = 月均客单价 × 客户生命周期月数
```

更精确需要考虑退款、流失分布。一人公司可先用简化版。**黄金比例 LTV/CAC > 3** 是健康区间（>1 回收成本但没钱扩，<1 烧钱模式）。回收周期（CAC Payback Period）也是关键指标——三个月内回收的健康，十二个月的要小心。

### 8. 渠道转化漏斗——找出瓶颈

每一条推广渠道（ch09）独立跟踪转化漏斗：
```
访问 → 注册 → 激活 → 试用 → 付费
```
断在哪一级补哪一级；不是所有渠道同等对待——按 LTV/CAC 比排序投资。

## 仪表盘：一人公司的"驾驶舱"

最简单的实现：一张 Google Sheet / Notion，每周 30 分钟更新。

```
┌─────────────────────────────────────────────┐
│ 月度仪表盘（每周一更新）                       │
├─────────────────────────────────────────────┤
│ 现金跑道：X 个月 ↓                           │
│ MRR：$X （+X% WoW）                          │
│ NRR：X%                                    │
│ 7 日激活率：X% / 30 日留存：X%               │
│ CAC：$X / LTV：$X / LTV:CAC = X             │
│ 主渠道（X）漏斗各段转化率                      │
│ NPS：X                                      │
│ 本周 3 个数字变化 + 1 个假设调整              │
└─────────────────────────────────────────────┘
```

最后一行最关键：**没有行动的数据更新是浪费时间**。每周问自己：哪 3 个数字变了？哪个变化触发了什么决策？

## A/B 测试的诚实使用

一人公司低流量阶段**别做 A/B 测试**——需要的样本量你达不到（转化率 ±20% 通常要 1 万+ 样本/臂），跑出来的"差异"基本是噪声。

低流量阶段的替代：
- **整页重构**（影响远大于改一个按钮）
- **定性访谈**（5 个用户告诉你哪一页卡住）
- **单变量大改动**：比如价格改 3 倍、CTA 改完全相反的风格——看绝对变化是否明显
- 流量到一定程度（每月 ≥1000 转化事件）再上 A/B

## 归因：从"是什么"到"为什么"

仪表盘告诉你**是什么**（MRR 跌了 10%），归因回答**为什么**（流失了？获取少了？还是定价变化？）。三种基本方法：

1. **漏斗对照**：把漏斗拆到这一周与上几周对照，看哪段转化率变了
2. **同期群分析（cohort）**：看同一周新增的用户群体后续行为，区分"上周获取变差"与"上周获取的用户本身差"
3. **用户访谈**：MRR 跌的原因大概率就在 5 个流失用户的访谈里——产品真相是定性活的

## 基准速查

| 指标 | 健康基线 | 来源 |
|---|---|---|
| Web SaaS Day30 留存 | 20-40% | 行业经验，差异大 |
| App Day1 留存 | ~40% | 行业经验 |
| 落地页转化（含表单） | 6.6% 中位 / 11.45% Top10 | Unbounce/WordStream |
| freemium 转付费 | 中位 8% / 要卡试用 30% | ChartMogul 2026 |
| LTV/CAC | >3 健康；>1 可活；<1 烧钱 | 经验法则 |
| CAC 回收期 | <12 月 | YC/SaaS 通行规则 |
| NRR | ≥100%；优秀 ≥120% | SaaS 估值通行 |

## 坑与证伪

| 坑 | 核查 |
|---|---|
| "DAU 涨了生意就好" | DAU 是虚荣指标，不付费就归零。换成"周活跃付费用户" |
| "多设几个北极星" | 北极星只有一个；多个=没有北极星，全队不知道对齐哪个 |
| 忽略流失只看新增 | 多数 SaaS 的死亡方式不是没获取到新用户，是旧用户流失快于新用户进 |
| 数据稀疏阶段硬要"数据驱动" | 早期 80% 靠定性（访谈/信念/小数据），20% 数据辅助；规模到再切换比例 |
| A/B 测试解决一切 | 低流量是噪音放大器；先做对大方向，再做小优化 |
| 数据预言未来 | 数据只能描述已发生；预测得配假设检验，否则是占卜不是分析 |

## 小结

- 三个区分：数据≠数字 / 虚荣 vs 行动 / 数据驱动≠数据崇拜
- 八个核心指标：现金跑道→MRR→北极星→护栏→留存→CAC→LTV→渠道漏斗
- 仪表盘：每周更新、每条数据配一个行动；没有行动的数据更新是浪费
- 低流量阶段不用 A/B，用整页重构+定性访谈；规模后再精细化

## 思考题

> 1. 选你的北极星指标（必须**一个**），写出它的定义公式，写出对应的护栏指标。
> 2. 算你的现金跑道：当前现金 ÷ 月净流出。低于 6 个月？高优先级动作是什么。

---

**验收标准**：

- [ ] 有一个北极星指标 + 一对护栏指标，定义可被无歧义执行
- [ ] 仪表盘已搭建（哪怕只是 Sheet），能填出当前真实数字
- [ ] LTV/CAC 算得出；如果是 SaaS，NRR 算得出
