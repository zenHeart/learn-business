# ch9 自我运营

> 一人公司里，你就是那个需要被管理的资源。这一章把原来写给"带团队"的管理方法论，翻译成"带自己"的版本。

## 精力管理先于时间管理

一人公司的产能瓶颈不是小时数，是**高质量决策的次数**（每天 3-5 个是常见上限）。所以：

- 把唯一的深度时段给**创作/产品**（早上第一件事，别给邮件）
- 决策疲劳的对策是减少决策数：固定例行动作（内容日更模板、固定定价、固定回复时段），把意志力留给 ch2/ch10 级别的判断
- 每周留白半天：不排产。一人公司死于连续满负荷运转后的判断失准，不死于工作量不足

## OKR：一人的版本

目标制定用 SMART 校准（具体/可衡量/可达/相关/有时限），结果拆解用金字塔原理——**拆的是结果维度，不是执行路径**（按因果线或时间线拆出阶段结果）。

一人的 OKR 与团队版差异：

| 团队 OKR | 一人 OKR |
|---|---|
| 对齐工具（上下级拉齐） | 自我承诺装置（对抗自由职业的漂移） |
| 承诺型/愿景型分开 | 每季度 1 个承诺型足矣（8/2 原则：80% 聚焦主线） |
| 复盘给上级 | 复盘给"上个月的自己"——写下来的预期 vs 实际 |

复盘四步：回顾目标（当初意图/预期效果）→ 评估结果（达成没？哪个 KR 拖了进度）→ 分析原因（预期 vs 实际差异）→ 总结经验（下一轮改什么）。

## 决策分型：判断力的日常训练

| 决策类型 | 正确姿势 |
|---|---|
| 可逆 + 便宜 | 直接拍板，快速验证（判断力的练习场——改价格、改文案、发一篇内容） |
| 可逆 + 贵 | 小成本先导实验 |
| 不可逆 + 便宜 | 拍板 + 记录预期 + 事后复盘 |
| 不可逆 + 贵 | 数据 + 框架 + 找 3 个人挑战——最终仍是你署名拍板 |

判断力训练闭环：**决策 → 事前写下预期（3 个月后应看到什么）→ 到期对照 → 偏差归因**。归因分三类：信息不足（流程问题）/ 框架错误（维度想岔）/ 判断失误（真正的训练素材）。

警惕的代偿信号：反复说"这不是拍脑袋"并用评分系统替自己背书——框架是沟通工具不是判断力本身。反方最强论点写不出来的判断，不值得署名。

## 孤独与可持续

一人公司最大的隐性成本不是钱是**孤独**——没有同事的校验，判断的偏差会复利积累：

- 最低配置：一个 5-10 人的同路人群（月度互查对方的"决策预期"，互相当挑战者）
- 每季度一次"外部眼睛"：找一位同行为你的产品/定价/方向做无情评审（付费也值——这是买校验，不是买安慰）
- burnout 的预警信号：内容开始纯搬运、回复客户开始烦躁、对数据失去好奇——出现两条以上强制休一周

## 坑与证伪

| 坑 | 事实 |
|---|---|
| 用自律对抗一切 | 一人公司失败访谈里"自控能力差会比上班还辛苦"是高频原话。解法是系统（固定例程、减少决策）不是意志力 |
| 7×24 全情投入 | 深度工作 4-5 小时/天已经是一人公司的实际上限（剩下是协作与执行）。比时长的是耐力赛——三年的 70 分节奏 > 三个月的 120 分燃烧 |
| 直觉决策=拍脑袋 | 直觉是内化的模式识别，只在有充分同类经验的领域可靠（Kahneman 的适用条件：环境规律+反馈质量）。你的利基内信直觉，新领域信数据 |
| OKR 太重 | 一人版本每季度花 2 小时定、每周 15 分钟对齐就够。做成表格仪式本身就成了新坑 |
