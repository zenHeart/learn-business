# ch05 定位与验证

> **本章目标**：把 ch04 的需求变成一个可防守的市场位置（三环定位 + STP 小白版），并用最便宜的方式验证它（落地页/预售/时间盒），拿到"第一笔真金白银"的信号再动手做产品。

## 真实场景

两个同期起步的独立开发者。A 验证的方式是"埋头做三个月，做出来大家自然会喜欢"——上线当天，沉默。B 的方式是先花一天做了一个页面："帮外贸卖家自动回复询盘邮件，每月 299 元，首批 20 个名额半价"，发到两个外贸社群——三天收到 7 笔预付。**同样的开发能力，B 在动手写代码之前就已经盈利了。**

## 定位：从需求到位置

ch04 找到了需求，定位回答"我在这个市场里站在哪"。营销学的经典框架 STP，一人公司版：

```
S 细分（Segmentation）：把市场切成小片 —— 按行业/角色/场景切
T 选择（Targeting）：选你能服务好的一片 —— 大到养活你，小到没对手
P 定位（Positioning）：在那片用户心里占据一个词 —— "提到X就想到你"
```

### 三环定位法（可操作的 STP）

| 环 | 问题 | 检验标准 |
|---|---|---|
| 能力环 | 我比 90% 的人更懂什么？（技术/行业/审美/人脉都算） | 有人为这项能力付过钱/求过你 |
| 痛点环 | 谁在为什么问题持续花钱？（ch04 的产出） | 搜得到高频吐槽 + 有付费证据 |
| 利基环 | 大到够养活一人、小到大厂看不上 | 能具体到"XX行业的XX角色" |

**三环交集 = 你的位置。** 缺任何一环都不是好定位：只有能力没痛点是自嗨；只有痛点没能力是眼馋；交集太大就继续切小。

反例与正例（记住这个对照）：

```
✗ "AI 写作助手"          —— 赛道思维：和所有大模型、10000 个独立开发者竞争
✓ "亚马逊跨境电商 Listing 优化助手" —— 利基思维：3000 个付费用户就能养活自己
```

**赛道是竞争的池子，利基是垄断的角落。** 一人公司永远选角落。

### 一句话定位公式

```
帮助【具体人群】用【你的能力】解决【具体问题】
```

"帮助外贸业务员（人群）用 AI 邮件生成（能力）解决询盘回复慢且不专业的问题（问题）"——说不清这句话 = 定位还没完成。这句话同时是你落地页的第一行（ch10）。

## 验证：用最小的代价买真相

### 验证的唯一标准

**有人付出代价表达意愿。** 点赞、夸奖、"挺好的"都不算——社会期许偏差让人说你想听的话。代价从轻到重：留邮箱（免费动作）→ 付定金 → **预售全款**。

### 验证落地页：一天的投入换三个月的真相

最小验证落地页四要素：

1. **一句话定位**（上面的公式直接用）
2. **痛点共鸣**：ch04 访谈里摘的用户原话（"每周花 6 小时手写回复，还经常词不达意"）
3. **价格锚**：写明预期价格——**标价后的兴趣才是兴趣**；可选"首批名额半价"制造稀缺
4. **转化动作**：预售按钮 / 等待名单

流量不用买：目标社群发一篇深度内容、10 个精准用户私发、相关话题下回答问题。基准：全行业落地页转化率中位 6.6%（Unbounce 2024，含表单点击；**不等于付费**），另一口径均值 2.35% / Top10% 11.45%+——低流量阶段（<1000 UV）转化率没有统计意义，看绝对数：多少封预付邮件比百分比诚实。

### 时间盒：验证的纪律

被反复验证的节奏（2026 一手访谈 + Indie Hackers 共识）：

```
想法 → 落地页/预售验证：1-3 天
验证通过 → MVP 上线：2 周（AI 辅助开发中位）
方向不对 → 换下一个：数周内决策
```

**事前写下换向标准**（"2 周内 0 预售即放弃"），防止事后合理化——人会在沉默的结果里给自己找继续的理由。Marc Lou 的 21 个产品 12 个活，靠的不是眼光而是纪律：每个验证便宜（<$500）、失败快速换向。组合的成功率来自单次失败的低成本。

## 从定位到品牌的衔接

定位稳定后（有付费用户、有复购），它会长成品牌——"提到 X 就想到你"。品牌不是 logo，是**用户心智中你占据的那个词**。个人生意的品牌 = 人格一致性（你长期公开说的话、做的事，ch08）+ 结果证明（案例，ch10）。这一步不着急，前 100 个用户靠定位就够。

## 坑与证伪

| 坑 | 核查 |
|---|---|
| "先做大再切小" | 顺序反了：先小到能垄断一个微利基（可防守），站稳后再扩（ch15）。起点就做大 = 在所有人的地盘作战 |
| "跟着风口做" | 风口 = 最大竞争池。跑通的都是垂直小切口的老手（外贸 AI、弹幕游戏——全是行业认知+AI，不是纯风口） |
| "等做出来再验证" | 最贵的顺序错误。代码是最贵的验证材料；预售页是最便宜的。B 的三天 7 笔预付 vs A 的三个月沉默 |
| 免费内测收集反馈 | 免费用户给兴趣反馈，付费用户给价值反馈。样本要小而付费 |
| 验证失败 = 我不行 | 验证失败是**这个需求-位置组合**不行，数据帮你省了三个月——换向是流程的一部分，不是对人的否定 |

## 小结

- STP 的一人公司版 = 三环交集（能力×痛点×利基）；一句话定位公式写不出 = 没定位完
- 验证唯一标准是**代价**：预售全款 > 定金 > 名单 > 点赞
- 落地页四要素 + 1-3 天 + 事前换向标准 = 完整的验证纪律
- 赛道是竞争的池子，利基是垄断的角落
