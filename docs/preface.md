# 开篇词 | 为什么一个技术人要懂商业

> 你有没有过这样的时刻——凌晨一点，代码合并进主干，CI 全绿。你看着那个构建成功的徽章想：这个功能，公司赚了多少钱？我在其中值多少？然后发现，你回答不了。你只知道你的月薪，不知道你的价值。

你好，我是 zenheart。一名写了很多年代码、后来开始系统研究"个人如何直接参与商业"的工程师。这本书是我把散落在几十本书、几百篇访谈和大量失败尝试里的商业知识，整理成一本"技术人也能从头学会"的教材的过程——写给我自己，也写给每一个想过"除了上班，我的能力还能怎么换钱"的你。

## 你可能正在经历的三件事

**第一，能力值钱的错觉。** 你能做出别人做不出的东西，但这个能力一旦装在公司里，你只能按职级定价。能力与收入之间隔着整个雇佣结构，而你对这个结构的运作一无所知——需求从哪来？价格谁定的？客户为什么付钱？这些问题在你的职业训练里全是空白。

**第二，AI 时代的推力。** 一人公司的存量已经超过 1600 万家，单人创始的新企业占比五年里涨了一半以上。同时被反复引用的另一面是：52.7% 的一人公司月入不足 7000 元。门槛在塌，成功率没涨——**机会属于既懂执行又懂商业的人**。AI 把执行的价格打了下来，商业判断成了新的稀缺品。

**第三，知识的碎片。** 你刷到过无数"独立开发月入十万"的帖子，也买过商业课程，但你拼不出一张完整的图：定位、验证、产品、定价、获客、转化、数据、财务——它们是什么关系？先后顺序是什么？每一步的行业共识和被验证的坑是什么？碎片知识撑不起一个决定。

## 这本书的论点

**一人商业化是一门可以系统学习的工程学科**，不是天赋、运气或鸡汤。它有完整的生命周期（洞察需求 → 产品 → 运营 → 推广 → 数据 → 经营自己 → 增长与终局），每个环节都有被反复验证的方法、可以查到的基准数据、以及被证伪的流行说法。这本书按教材的方式把它们组织起来：

- 每章开头有**本章目标**，结尾有**验收标准**——学完一章，你能判断自己会不会了
- 所有关键数字带**口径与来源**（附录集中索引），头部叙事旁边永远摆着中位数
- 每个流行方法都配**坑与证伪**——先告诉你什么时候它不管用，再教你怎么用

它不会承诺你财务自由。它承诺的是：读完之后，"我的能力怎么变成一门生意"这个问题，你会有一套自己的、有依据的答案。

## 这本书怎么读

- **零基础读者**：从第一章顺读。第一部分（认识商业）为一切打底，跳过它你会一路遇到似懂非懂的概念。
- **有副业经验**：直接去你卡住的那部分——做不出产品的看第二部分，没流量的看第四部分，数据看不懂的看第五部分。
- **只想要数字**：直接查[附录·基准数据速查表](/appendix/benchmarks)。
