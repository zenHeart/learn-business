# 附录：Creem 与 Polar 的 MoR 费率与提现条款速览

> 结论先行：Creem 与 Polar 都是商户记录人（Merchant of Record，MoR），差异在定价结构。Creem 是一口价：每笔 3.9% + 0.40 美元，无月费，每月 1 日与 15 日提现（S1）。Polar 免费的 Starter 档为每笔 5% + 50 美分，付费计划可降低浮动费率，提现需手动发起且有 7 天结算延迟（S3、S5）。抓取日期：2026-10-25，仅采信两家官方域名的页面原文。

写给谁：打算向海外销售数字产品、想比较 MoR 平台回款条款的一人公司创作者。前置知识：已读 ch07 定价与 ch13 财务合规。本页只整理条款，不含注册或选型建议。

## 1. Creem

| 项目 | 官方表述 | 来源 |
|---|---|---|
| 是否 MoR | 是，税务、合规与拒付一并处理 | S1 |
| 费率 | 每笔成功交易 3.9% + 0.40 美元，无月费、无设置费 | S1 |
| 间接税 | 交易环节的间接税合规由 Creem 承担 | S2 |
| 直接税 | 提现款项的所得税、公司税等由卖家自行申报 | S2 |
| 提现 | 需达到最低余额要求并主动发起；每月 1 日与 15 日处理，可到银行账户或 USDC 钱包 | S1、S2 |
| 地区限制 | Creem 可限制部分国家或地区使用服务，名单以官网为准 | S2 |

## 2. Polar

| 项目 | 官方表述 | 来源 |
|---|---|---|
| 是否 MoR | 是，承担国际销售税责任 | S4 |
| 费率 | 2026 年 5 月 27 日及以后新建组织默认 Starter 档 5% + 50 美分；Pro、Growth、Scale 三档付费计划可降低浮动费率 | S3 |
| 提现门槛 | 余额达到账户币种对应的最低门槛即可发起 | S5 |
| 结算延迟 | 2026-05-12 起新建组织默认 7 天；此前组织保留即时可提现，风险审核可能延长 | S5 |
| 提现方式 | 手动发起，没有自动提现日程 | S5 |
| 提现费用 | 有提现的月份收取 2 美元，每笔另收 0.25% + 0.25 美元；跨境换汇另收欧盟 0.25%、其他地区最高 1%；通常 4–7 个工作日到账 | S5 |
| 提现账户 | 经 Stripe Connect Express 向支持地区的个人或企业付款 | S4 |
| 地区限制 | 全球收款，不含美国制裁国家（古巴、俄罗斯、伊朗、朝鲜、叙利亚） | S4 |

## 3. 对比

| 维度 | Creem | Polar |
|---|---|---|
| 费率 | 3.9% + 0.40 美元，无月费 | Starter 5% + 50 美分；付费计划可降浮动费率 |
| 提现节奏 | 每月 1 日、15 日 | 手动发起，新组织默认 7 天结算延迟 |
| 提现成本 | 未公布 | 活跃提现月 2 美元 + 每笔 0.25% + 0.25 美元，可能另有跨境换汇费 |
| 税务责任 | 间接税归 Creem，直接税卖家自担 | 国际销售税归 Polar |
| 限制 | 可限制部分国家或地区 | 不收制裁国家款项；提现需 Stripe Connect Express 支持地区 |

按条款推断（非官方建议）：小额起步时，Creem 的单一费率更容易估算；月销量稳定后，可用 Polar 付费计划的实际费率重算一次再比较。
