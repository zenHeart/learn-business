## 2. 案例

### TypingMind：买断打底，再转团队订阅

- **产品**：自带 API key 的多模型聊天前端。原文称在 OpenAI 开放 API 后第 5 天上线。
- **获客**：付费广告与赞助效果差，作者已停；2025-10 披露最近一次投放花 $600 只换 2 次转化。自然流量来自社交媒体提及与口碑。
- **定价**：个人版一次性买断，云同步与团队版走订阅；原文未给单价，本页不写价格。
- **做法（原文支持）**：产品本体是纯静态 web app，无后端和数据库，只靠 license key 激活，托管成本近零，因此敢卖买断；买断拿到个人用户后，再把一部分转成团队订阅。
- **前提（原文支持 / 推论）**：抢到品类空窗、且创始人自带较大受众。推论：今天没有这两个条件时，结构仍可借鉴，但起量速度和获客成本不能照搬。

### PDF.ai：品类域名 + $99 终身版验证

- **产品**：上传 PDF 后对话问答；创始人买下他人的周末项目后重新定位变现。
- **获客**：品类词域名，大部分流量来自"PDF AI"类搜索的自然排名。
- **定价**：用 $99 终身买断测试付费意愿，三个月内换到 300+ 付费用户，再决定是否继续投入并雇用全职工程师。
- **前提**：起点是收购已有项目；exact-match 品类域名几乎不可复制（推论）。$99 终身是一次性现金流，适合当验证工具，不适合当商业模式（推论）。

### Chatbase：公开构建，零预算起量

- **产品**：早期是上传书籍后对话的窄 B2C 工具，后转向 B2B 的客服 / 销售 agent。
- **获客**：前三个月无营销预算，每天在 Reddit、Twitter、LinkedIn 公开构建。
- **定价**：最低档从 $19 提到 $40，最高档从 $300 试到 $500，把价格当可反复调整的实验变量。
- **前提**：117 天 $1M ARR 是极端速度，不能当基线；$10M ARR 阶段已不是一人公司形态（推论）。

## 3. 可迁移的模式（跨案例归纳，非任何作者原话）

**窄工具 + 一次性买断做付费验证 → 转团队订阅提高客单；分发靠品类词搜索与垂直社区，前期不买广告。** 对中文创作者，可替换的是渠道层（英文品类词 SEO 出海 + 中文垂直社区），不可替换的是顺序：先卖一次性的窄工具换真实付费，再决定是否转订阅。

## 缺口

- 三位创始人的 X / LinkedIn 原帖未抓到正文（需登录或依赖 JS 渲染），收入数字改用 newsletter、访谈与播客页。
- PDF.ai 与 Chatbase 的访谈页未标注发布日期；TypingMind 与 PDF.ai 的官网价目页未读，定价只写原文能支持的部分。
