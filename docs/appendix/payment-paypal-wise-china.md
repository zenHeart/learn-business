# 附录：PayPal 与 Wise 收款到中国大陆账户速查

> 结论先行：PayPal 的收款属于“商业交易”，提现到中国大陆走电汇美元（最低 150 美元、3–7 个工作日、每笔收费）；Wise 账户收款基本免费，可转入本地银行账户，收款方无需 Wise 账户，常见路线 1 天内、同日甚至即时到账。两家的具体费率数字都不在已抓取的正文里，使用前须回官方费率页核对。抓取日期：2026-10-31。

写给谁：打算用 PayPal 或 Wise 收海外款项、并提现到大陆银行账户的一人公司创作者。前置知识：已读 ch13 财务合规与现金流。

## 1. PayPal（中国大陆站）

- 用“收款”功能接收付款，在 PayPal 的定义里属于“商业交易”，按商家费率体系计费（P1）。
- 大陆站“消费者费用”页正文没有给出收款费率，只指向商家费用页（P1）。
- 提现前提是把资金提到关联银行账户；可提现至本地（大陆）、香港、美国银行账户，也可申请支票（P2）。
- 提现到中国大陆走电汇美元：最低提现额 150 美元，资金 3 到 7 个工作日到账，每笔提现收取费用（P2）。

## 2. Wise（中国站）

- 用账户余额汇款需持有 Wise 多币种账户；收款方则不需要 Wise 账户（P4）。
- Wise 账户收款免费；美元电汇等更快方式收固定费用，但总有免费的替代方式（P3）。
- 除美元和新加坡元外，大多数货币没有收款限额（P3）。
- 转出后进入本地银行账户；页面示例中最便宜的路径是使用账户余额，示例成本 54.22 USD（P4）。
- 常见路线可 1 天内、同日甚至即时到账（P4）。

## 3. 对照

| 维度 | PayPal | Wise |
|---|---|---|
| 账户要求 | 收款属商业交易；提现需关联银行账户 | 余额汇款需多币种账户；收款方无需 Wise 账户 |
| 收款费用 | 正文未给出，指向商家费用页 | 账户收款免费；更快电汇收固定费 |
| 转出方式 | 本地、香港、美国银行账户及支票；大陆走电汇美元 | 转入本地银行账户 |
| 转出费用 | 每笔提现收费，金额正文未给出 | 余额汇款示例 54.22 USD |
| 到账与限额 | 3–7 个工作日；最低提现 150 美元 | 1 天内 / 同日 / 即时；多数货币无收款限额 |

来源：P1–P4。

## 4. 对一人公司的检查清单

以下由上文官方表述推出，不是官方建议：

1. 先确认 PayPal 的商家费率与电汇每笔费用，再决定是否把它作为主收款入口。
2. 小额订单要把 PayPal 的最低提现额 150 美元和 3–7 个工作日的周转计入现金流预期。
3. 需要快速、低成本落地时，优先评估 Wise 的余额汇款路径，并核对目标币种的收款方式与费用。
4. 面向客户的到账说明，两个渠道按各自时效分别书写。
