# 附录：Stripe 退款与拒付速查

> 结论先行：退款是商家主动把钱退回原支付方式，普通退款不退还原交易的处理费；拒付是持卡人向发卡行发起的反向扣款，金额和争议费先被扣走，举证窗口只有 7–21 天，判负后无法追回。本页只收录 `docs.stripe.com` 官方文档中的机制，常规费用的具体数字所抓页面未给出。抓取日期：2026-10-31。

写给谁：准备用 Stripe 收款的一人公司，需要在设计退款政策和现金缓冲前，知道退款与拒付各自的资金流向和时限。前置知识：已读 ch13 财务合规与现金流。

## 1. 退款

- 由商家在 Dashboard 或 Refunds API 主动发起，可全额或部分退款（S1）。
- 只能退回原交易所用的支付方式，不能改退到其他卡或账户（S1）。
- 发起后，客户一般在约 5–10 个工作日内看到入账，具体取决于银行（S1）。
- 普通退款（refund）不退还原交易产生的 Stripe 处理费。例外：退款紧接原扣款并按撤销（reversal）处理时，官方说明不会扣留处理费，详见 S1 的 “refund and reversal” 一节。

## 2. 拒付

- 持卡人向发卡行质疑某笔付款后形成拒付（chargeback）（S2）。
- 拒付成立后，Stripe 从商家余额中扣走交易金额和争议费（S2）。
- 收到通知后通常只有 7–21 天举证，具体取决于卡组织（S3）。
- 判负后，退款永久成立，争议费不退回（S3）。
- 例外费用：S3 提到，争议 Visa 或 Mastercard 的 compliance dispute 时，会额外收取 500 USD（或当地等值）的网络费用，胜诉时退回。

## 3. 对照

| 维度 | 退款 | 拒付 |
|---|---|---|
| 触发方 | 商家主动发起 | 持卡人向发卡行提出 |
| 时间 | 发起后约 5–10 个工作日到账 | 收到通知后 7–21 天内举证 |
| 费用 | 普通退款不退原交易处理费；reversal 例外 | 交易金额与争议费被扣走；判负后争议费不退；compliance dispute 另有网络费 |
| 资金流向 | 退回原支付方式 | 先从商家余额扣款，判负则不可追回 |

来源：S1–S3。

## 4. 对一人公司的检查清单

以下均由上文官方限制推出，不是官方建议：

1. 退款政策只承诺“原路退回”，避免承诺退到其他卡。
2. 预算时把普通退款的处理费视作固定成本，客单价低时影响更明显；若能在原扣款后立即撤销，先确认是否符合 reversal 条件。
3. 在客服话术中给出 5–10 个工作日的到账预期，减少“未收到退款”的二次投诉。
4. 余额里为拒付预留缓冲：拒付成立会立刻扣走交易金额和争议费；若涉及 compliance dispute，另需预留 500 USD 量级的网络费。
5. 收到拒付通知当天开始整理举证材料，窗口只有 7–21 天。
6. 判负后无法追回，对胜算很低的争议要权衡是否值得提交。
