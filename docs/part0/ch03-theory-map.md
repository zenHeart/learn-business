# ch03 商业化理论最小集

> **本章目标**：把一人公司需要的经济学/商学概念压成一张最小地图（供需、边际成本、价格弹性、机会成本、复利与杠杆、商业模式画布），每个概念配一人公司场景的例子。学完本章，后面六章出现的所有"行话"你都有了定义。

## 真实场景

一位独立开发者抱怨："我把价格从 99 元降到 39 元，销量只涨了一点点，收入反而跌了。"另一位做急救咨询的朋友却说："我涨价 50%，客户一个没少。"——两个人遇到的，是同一个概念的两面：**价格弹性**。这一章把这些"看不见但天天起作用"的概念一次讲完。

## 需求侧四概念

### 1. 供需（为什么你的报价被压）

最古老的模型：供给多、需求少 → 价格跌；反之价格涨。

一人公司场景：某个利基里"同类独立设计师"从 100 人涨到 10000 人（AI 降低了设计门槛），同等质量的报价必然被压。**应对不是更卷，是换到供给还没涌进来的利基**（ch04 洞察需求的逻辑起点）。

### 2. 边际成本（数字生意的魔法）

多卖出一**单位**产品/服务，额外增加的成本。

- 制鞋厂：每双鞋都有材料和工时 → 边际成本高
- 已录好的课程/软件订阅：多卖一份几乎为零 → **边际成本≈0**

这是数字产品/软件成为一人公司首选的结构性原因（ch06 产品化阶梯的理论根据）：收入随销量线性增长，成本几乎不涨。信息品"高固定成本、近零边际成本"的特性（Shapiro & Varian《信息规则》）同时意味着：**定价不该锚定成本，该锚定价值**（ch07）。

### 3. 价格弹性（降价的两种结局）

需求对价格变化的敏感度：

- **弹性大**（对价格敏感）：降价 → 销量大增。常见于替代品多的市场（模板、通用工具）
- **弹性小**（对价格不敏感）：降价销量几乎不动，纯亏收入。常见于止痛型/无替代品的场景（急救咨询、独家数据）

一人公司场景速查：**替代品越多越弹性，痛点越急越不弹性**。所以定价策略前先问：用户不买你的，买什么？（没有答案 = 不弹性 = 可以涨价）

### 4. 机会成本（你真正付出的价格）

做一件事的成本，是你因此**放弃的最优选择**的价值。

一人公司场景：接一单 2 万元的定制开发，机会成本是同期可以完成的订阅产品迭代（未来每月多 $500 MRR）——这单"看起来赚 2 万"的生意可能是亏的。一人公司最大的隐形机会成本是：**你的时间只有一个去向**（ch14 自我运营会反复回到这里）。

## 增长侧两概念

### 5. 复利（一人公司的底层信仰）

`终值 = 起点 × (1 + 增长率)^时间`。商业里能复利的东西：受众的信任（每周内容 × 两年）、产品的口碑（每个满意用户带新用户）、内容资产的搜索流量（每篇长文持续引流）。

复利的反面是线性和一次性：接单（线性，停手停收）、投放买量（一次性，钱停流量停）。**一人公司一切"慢动作"（内容、SEO、口碑）都是复利动作，一切"快动作"（买量、热点）都是线性动作**——启动期需要快动作活下来，长期靠复利动作滚起来（ch15）。

### 6. 杠杆（不加人的规模化的全部秘密）

Naval Ravikant 的四类杠杆，按"无需许可"排序：

| 杠杆类型 | 例子 | 一人公司可用度 |
|---|---|---|
| 劳动力 | 雇人 | ✗（违背一人前提，ch16 才讨论） |
| 资本 | 融资、借贷 | ✗（一人公司融资难，ch13） |
| **代码/产品** | 软件 24×7 替你干活 | ✓ 核心 |
| **媒体/内容** | 一篇文章服务 10000 人 | ✓ 核心 |

**一人公司 = 放弃前两类杠杆，把后两类用到极致。** AI 是杠杆的杠杆：它把"做产品、做内容"的执行成本也打下来了（ch12）。

## 商业模式画布：一页纸描述你的生意

所有概念落到一张纸上。Alexander Osterwalder 的商业模式画布九格，一人公司版简化成五问：

```
① 客户细分：具体帮谁？（ch04——必须具体到"XX行业的XX角色"）
② 价值主张：帮他解决什么痛/省什么时间/给什么感受？（ch01 价值公式）
③ 渠道与客户关系：他在哪被你触达、为什么信你？（ch08-ch10）
④ 收入来源：订阅/买断/服务，定价多少？（ch06-ch07）
⑤ 成本结构与关键资源：工具栈+你的时间+AI 成本（ch12-ch13）
```

填这张纸的纪律：**每格写句子不写名词**。"客户：年轻人"不合格；"客户：帮 25-35 岁跨境电商卖家做Listing优化"合格。写不出句子的格子 = 你的知识缺口 = 后面对应要精读的章。

## 坑与证伪

| 误解 | 修正 |
|---|---|
| "经济学没用，做生意靠感觉" | 四概念全部可操作：供需告诉你选利基、边际告诉你选品类、弹性告诉你敢不敢涨价、机会成本告诉你接不接单 |
| "复利=睡后收入=躺赚" | 复利前期极其缓慢（内容两年才起量是常态），把它当躺赚的人熬不过平缓期 |
| "画布是形式主义" | 画布的价值是暴露知识缺口——填不出的格子就是你下次失败的地点 |

## 小结

- 需求侧四概念：供需（选利基）、边际成本（选品类）、价格弹性（定价格）、机会成本（选项目）
- 增长侧两概念：复利（慢动作）与杠杆（代码+媒体，一人公司的唯一规模化路径）
- 商业模式画布五问是检验知识缺口的工具：写不出句子的格子就是你要补的章

## 思考题

> 1. 你能提供的产品/服务里，哪个边际成本最低？哪个价格弹性最小？（两个答案如果是同一个，恭喜——那是你的最佳起点）
> 2. 填一次五问画布，诚实标出写不出句子的格子。
