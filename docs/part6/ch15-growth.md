# ch15 增长

> **本章目标**：把增长从玄学变成结构——按收入阶梯选择打法，避免用错阶段的方式烧钱；掌握一人公司的四种"不加人"杠杆；会跑 RARRA 体检避免往漏桶里倒水。

## 真实场景

一个开发者月入 $145（独立产品 MRR 中位数），看到 Justin Welsh 年入 $400 万的帖子后开始日更、发广告、雇外包——三个月后累垮，账户只多了 $200。**问题不是增长，是用 $10k 阶段的打法打 $500 阶段的仗**。本章教你按收入阶梯选打法。

## 收入阶梯与分布现实

Indie Hackers 社区里程碑：首笔收入 → $1k MRR → $10k MRR。分布数据（Stripe 核验 + TrustMRR）：

```
有收入独立产品：MRR 中位 $145-500
能过 $10k MRR：约 3-6%
中位与头部之间隔着两个数量级
```

**每一段的打法不同，混用是常见失败原因**：

| 收入段 | 核心任务 | 死法 |
|---|---|---|
| $0 → $500 | 验证需求 + 跑通销售 | "等做完美再上" / "调研太多不行动" |
| $500 → $1k | 拉留存 + 复购 | "还没稳就开投放" |
| $1k → $10k | 结构化获客 + 提客单 | "盲目扩张品类稀释" |
| $10k → $100k+ | 系统化 + 选终局（ch16） | "不敢放手加杠杆" |

## 四种不加人的杠杆

按"杠杆强度 × 难度"排序，匹配你的收入段：

### 杠杆 1：价格杠杆（最便宜，几乎人人可用）

ch07 已展开。这里重申它在增长中的角色：**转化率不变，客单价 ×2 = 收入 ×2**。这是没增加任何成本的增长。涨价步骤见 ch07 的纪律。

### 杠杆 2：产品杠杆（让产品自己干活）

- **内置传播**：产出物带署名/角标（"用 X 制作"），用户的每次使用都在展示
- **SEO**：工具型产品的自然流量复利（Levels 的组合主打法：AI 生成内容+自动化客服+SEO）
- **集成市场**：上架 Slack/Chrome/飞书/Notion 生态——借平台分发

### 杠杆 3：内容杠杆（受众的复利）

ch08 已经说过。当飞轮进入复利区：老内容持续带来订阅/咨询（存量内容开始工作，你不再为流量逐篇付费）。此时增长动作只剩两个：提高回收精度（哪类内容带转化）、复制已验证的内容形态。

### 杠杆 4：组合杠杆（Small Bets）

Daniel Vassallo 路线（2019-2024 年收 $33k→$620k，自报）：**同时押多个小赌注，砍掉不工作的，加倍工作的**。

```
组合的纪律：
- 每个 bet 固定小预算（时间/金钱封顶）
- 预设止损线（事前写，防事后合理化）
- 赢家加注靠数据不靠感情
```

Marc Lou 同构（21 个产品 12 个盈利 / 57%）。**前提是单次验证便宜**（ch05）——他多数产品启动 < $500。如果你的每个 bet 启动成本是几个月，那不是组合，是赌博。

## 增长模型与它们的局限

### AARRR 与 RARRA

AARRR（获客→激活→留存→收入→推荐）是最常用的诊断框架。已知局限：
- **单向漏斗无复利**：底部产出不能回流顶部，模型里没增长飞轮的位置
- **按层切团队导致局部优化**：营销灌水+下游留存崩
- **阶段并非严格顺序**：双边市场非线性（付费可能先于激活）

**RARRA**（Retention→Activation→Referral→Revenue→Acquisition，GrowthHackers 共识）：**留存没跑通之前，不投获客。** 经典场景：往漏桶里倒水 = 一人公司最贵的错误。

```
留存未跑通前 → 停止一切获客预算 → 把所有精力放到留存修复
留存跑通后 → 再启动获客
```

### 北极星指标与护栏

ch11 已详。增长阶段的高频陷阱：指标做坏。**主指标 + 护栏指标** 始终配对——激活率↑ 但 30 日留存↓ = 假激活；订单量↑ 但客单价 × 毛利率↓ = 卖便宜货。

## "幻象增长"识别清单

- 流量涨但收入不涨 → 流量质量差（来源不对）或转化页问题（ch10）
- 收入涨但用户数不涨 → 涨价驱动（一次性的）；下一步是看留存能否跟上
- 用户数涨但收入不涨 → 用户是羊毛党（免费用户混入）；看活跃与付费转化
- 全部指标涨但跑道不涨 → 单位经济差（LTV<CAC），随时崩盘

## 坑与证伪

| 坑 | 核查 |
|---|---|
| 增长黑客速成 | 增长是结构的产物：留存×转化×传播的结构没搭好之前，"黑客技巧"只是往漏桶倒水的不同姿势 |
| 投放买量 | 没留存数据时投放是盲注。先榨干免费杠杆（SEO/受众/传播内置），再考虑付费 |
| 什么都自己做 | 增长阶段可以买回时间：剪辑/设计/初稿外包，判断保留——买的是杠杆不是判断 |
| 收入停滞=加产品 | 先查结构（定价？留存？受众匹配？）再加数量。结构问题用加法只会稀释 |
| 用 VC 框架套自己 | 一人公司不是 startup，目标是现金流复利不是估值翻倍 |

## 小结

- 按收入阶梯选打法（$500 阶段用 $500 阶段的方式，不是 $10k 的方式）
- 四种不加人杠杆：价格（最便宜）→ 产品 → 内容 → 组合
- RARRA 体检：留存未跑通之前不投获客
- 幻象增长四清单（流量/收入/用户/跑道哪个维度失配）
- 增长的目标是结构可复利，不是规模最大化
