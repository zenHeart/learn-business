# ch15 增长

> **本章目标**：建立增长阶段判断与杠杆选择——四种不加人杠杆、按 MRR 阶梯匹配打法、增长模型与已知局限（AARRR/北极星的坑）、不让"加了多个平庸产品"成为稀释。把 ch02-14 的所有杠杆在这一章收口到"如何复利"。

## 真实场景

一位独立开发者月 MRR $300，他最大的问题是焦虑——看顶级案例年入百万，拼命加功能、加大投放，但每加一动作都让结构变得更乱而不是更稳。半年后 MRR 仍 $300，但疲惫程度翻倍。**他没看到：从 $300 到 $3k 靠结构（杠杆），不是更努力**。

## 先校准：收入的真实分布

Indie Hackers 用收入阶梯当里程碑：

```
首笔收入 → $1k MRR → $10k MRR → $100k MRR → …
```

**分布数据（Stripe 核验样本 + TrustMRR，2026-09 取用）**：

- 有收入的独立产品：MRR 中位 **$145-500**
- 能过 $10k MRR 的：约 **3-6%**
- 中位与头部之间隔着两个数量级

这组数字的用法不是劝退，是**定位**——$145→$1k 靠执行（ch06-ch10 全部打通），$1k→$10k 靠结构（本节），$10k 往上靠复利与运气（ch16 决定要不要继续）。每段的打法不同，**混用是常见失败原因**——用 $10k 阶段的打法（雇人、投放）打 $500 阶段的仗，烧死在到达之前。

## 四种不加人杠杆

按"无需许可"排序——一人公司可用的只有后两类：

### 1. 产品杠杆：让产品自己获客

- **内置传播**：产出物署名/水印（Notion 模板"用 X 制作"角标、报表生成器结果页右下角 logo）
- **SEO**：工具型产品的自然流量复利——组合 1 篇文章 × 18 个月长期引流是 levels.io 的核心打法
- **集成市场**：上架 Slack/Chrome/Notion/飞书 集录，借平台分发（出海独立开发者标配）

### 2. 内容杠杆：受众的复利（ch08 复盘）

进入复利区的标志：**老内容持续带来订阅/咨询**（存量开始工作，你不再为流量逐篇付费）。此时动作只剩两个：提高回收精度（哪类带转化）、复制已验证的内容形态。**新动作边际成本高，复制老动作边际成本低**——这是复利的本质。

### 3. 价格杠杆：最便宜的增长

转化率不变，客单价 × 2 = 收入 × 2（ch07 的涨价纪律）。增高档位、年度订阅（一次性收 10 个月价换现金流）、企业定制档——都是不开发新功能的"增长"。

### 4. 组合杠杆：Small Bets

Daniel Vassallo 的路线（2019-2024 年收 $33k→$620k）：**同时押多个小赌注，砍掉不工作的，加倍工作的**。与 Marc Lou 的 21 个产品 12 盈利（57%）同构。纪律：

- 每个 bet 有固定小预算（时间/金钱封顶）
- 预设止损线（**事前写防事后合理化**，同 ch05 换向标准）
- 赢家加注的标准是数据不是感情

## 增长模型与它们的局限

AARRR（获客→激活→留存→收入→推荐）是最常用的诊断框架：

**已知局限**（必须知道）：
- 单向漏斗无复利（底部产出不能回流顶部）
- 按层切团队 → 局部优化（营销灌水、留存崩）
- 阶段并非严格顺序（双边市场非线性——付费可能先于激活）

**配套校准顺序**：RARRA（Retention → Activation → Referral → Revenue → Acquisition）——**留存没跑通之前，不投获客**——往漏桶倒水是一人公司最贵的错误。

北极星指标（一个最能代表用户价值的指标）用于对齐：

**已知坑**：
- 虚荣指标不合格（DAU/注册数/收入是结果不是价值）
- 指标一旦考核就被博弈（古德哈特定律）
- 单指标压不住多边业务（供需两端、不同使用模式）

**护栏必配对**：每个主指标配 1-2 个反向护栏（ch11 已讲）。

## MRR 阶梯 × 打法匹配

| 阶段 | 数字 | 主要杠杆 | 死亡陷阱 |
|---|---|---|---|
| 入门 | $0 → $1k | 预售+早期客户 | 永远免费/永远打磨 |
| **第一道槛** | **$1k → $10k** | **留存+口碑+SEO** | **投广告烧钱** |
| 第二道槛 | $10k → $50k | 产品杠杆+团队（ch16 终局选择在此） | 用劳动补自动化 |
| 第三道槛 | $50k+ | 内容资产复利/系统可移交 | 过度工程 |

**最常错位**：用 $10k 阶段打法（雇人、投放、品牌）打 $500 阶段的仗——结果是大量投入+微弱产出。**打当前阶段适合的仗**，不是打"想去的阶段"的仗。

## "减法策略"的回归

反直觉但被反复验证：很多成功的一人公司不是把一个产品做精，而是**砍掉一个产品里 80% 的功能**，只保留最有付费意愿的核心（ch01 的"减法"案例 Samuel，ch06 的 MVP 纪律）。**增长不一定靠加，也可以靠减**——减掉对老用户 80% 的服务成本，把释放出的精力用在复利动作（内容、SEO、新客户）。

## 增长与心智

Daniel Vassallo 的年收序列（自报）：

```
$33k → $351k → $337k → $541k → $467k → $620k
```

**波动是常态，路径不是直线**——$541k 后跌到 $467k，第二年才创新高。一人公司的增长是波动中的上行，不是直线爬升。学会在波动中保持判断（ch14 的决策复盘）是持续增长的前提。

## 坑与证伪

| 坑 | 核查 |
|---|---|
| 增长黑客速成 | 增长是结构的产物。留存 × 转化 × 传播的结构没搭好之前，"黑客技巧"是往漏桶倒水的不同姿势 |
| 投放买量 | CAC 在没有留存数据时是盲注。一人公司先榨干免费杠杆（SEO/受众/传播内置）再考虑付费 |
| 什么都自己做的天花板 | 增长阶段可以买回时间：剪辑/设计/初稿外包，判断保留 |
| 收入停滞=加产品 | 先查结构（定价？留存？受众匹配？）再加数量。结构问题的加法只会稀释 |
| 跟着中位数 | 一人公司是 MRR 中位 $145-500 的现实。中位"不丢人"，结构往上走才是目标 |

## 小结

- MRR 阶梯分四段，每段匹配不同杠杆与不同死亡陷阱
- 一人公司的四种不加人杠杆：产品内置、内容复利、价格杠杆、组合小赌注
- AARRR 的修正 = RARRA；北极星必配护栏；波动是常态
- 增长可以是减法（砍掉 80% 功能释放精力）；打当前阶段的仗

> 2. 选一个"减法"机会：你现有产品里能砍掉哪个 80% 功能、留住 20% 核心？
