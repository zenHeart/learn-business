# 简介

> 一本人人可学的个人商业化教材：从"什么是商业"讲到"终局怎么选"。

## 本书目标读者（学习者画像）

**零商业背景的技术/专业人士。** 画像假设：

- **会**：熟练使用电脑、互联网和 AI 工具；在自己的专业领域（写代码/设计/写作/行业知识）有积累
- **不会**：没有任何系统的商业训练——没学过经济学，没做过销售，看不懂"获客成本""转化率"背后的东西
- **想要**：把专业能力直接变成一门自己的小生意，而不是只能装在公司里按职级定价

超出画像的内容（如融资、股权设计、团队管理方法论）只在必要处以"进阶阅读"标注，不展开——它们属于"从一人到团队"的下一本书（附录保留了两篇全本供过渡）。

## 阅读建议

- **按顺序读**是默认姿势：七部分是严格的依赖链——理论（第一部分）打底 → 起点 → 产品 → 运营推广 → 数据 → 经营自己 → 增长终局。跳章会遇到没定义过的概念。
- 每章结构固定：**本章目标 → 真实场景 → 正文（概念/方法/基准）→ 坑与证伪 → 小结 → 思考题 → 验收标准**。验收标准是判真伪的，不是自我感觉——"能对别人讲清楚 X"比"我觉得看懂了"硬。
- 每章末尾的**思考题**没有标准答案，但下一章会用到上一章的答案——这是刻意的概念复述设计。
- 数字时效：全书基准数据取用时间 2026-09，商业环境变化快，附录给了信源链接，决策前请自查时效。

## 内容范围

**涵盖**：商业本质与理论最小集、需求洞察与验证、产品化、定价、内容运营、推广获客、转化销售、数据体系、财务法务（中国语境为主）、自我运营、增长、终局。

**不涵盖**：融资与股权、团队组建与管理（附录有全本过渡读物）、具体技术教程、平台规则细则（变化太快）、税务/法律的具体意见（给框架，具体操作请咨询专业人士）。
