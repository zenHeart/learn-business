## 为什么有这个站

2026-09 对个人历史项目对话的一次分析发现：多个互不相关的项目里反复出现「不是拍脑袋」「不是凭感觉」的防御性措辞——用打分板、Rubric、检索证据等工程手段**代偿**商业判断力。

这个站点的方法论立场：框架（评分、漏斗、指标）是**沟通与对齐工具**，不是判断力本身。判断力的来源是：真实场景的取舍记录 + 复盘。因此每篇文章都带两节固定内容：

- **已知局限**：这个框架被业界证伪/吐槽的部分（来自公开的官方文档与业界共识线索）
- **给自己的锚点**：一个可执行的练习或检查清单

## 隐私边界

本站为个人学习知识库：不含公司内部信息（项目代号、内网、同事与绩效数据），原始工作材料不入库，仅保留中性化的场景描述。
