## 这本书的立场

1. **先看中位数，再看头部叙事。** 一人公司存量超 1600 万家（占全国企业 27.4%），但 52.7% 月入不足 7000 元；有收入的独立产品 MRR 中位数只有 $145-500。头部案例（$3M/年）是幸存者，本书每章同时给"叙事"和"中位数"。
2. **生命周期视角。** 定位 → 验证 → 产品 → 获客 → 转化 → 交付 → 规模化 → 终局，八阶段各有各的失败模式。跳阶段的代价远大于做错单点。
3. **终局先想清楚。** "维持小而美"和"做成卖掉"是两条不同的路（Jarvis vs Levels），价值观决定阶段策略——这不是最后一章的内容，而是第一章就该问自己的问题。
