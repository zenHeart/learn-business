# 第 12 章 战略框架：波特、SWOT、BCG 与好坏战略鉴别

> **能力对应**：strategic-frameworks
> **学习目标**：能应用波特三大战略、SWOT、BCG 矩阵、Good Strategy/Bad Strategy 检验制定战略叙述。

## 真实场景

一位创始人写了 30 页商业计划书，从市场讲到财务，但被合伙人问"你的战略是什么"时，他说不出 3 句话。他的计划书是"商业汇总"不是"战略"。问题是他没有用战略框架把分散信息压缩成"做什么、不做什么、为什么"。

## 为什么战略框架在 L2 中段

战略框架不解决执行细节（那是 GTM 和增长循环的事），而是提供一种"压缩"工具——把市场、竞争、商业模式压缩成可被合伙人/投资人/团队复用的战略叙述。

## 第一节 战略与战术的区别

- **战略**（Strategy）：做什么、不做什么、为什么。回答 Why 和 What。
- **战术**（Tactic）：具体怎么做。回答 How。

L2 强调：**战略必须能用一句话表达**。不能一句话表达 = 没有战略，只有战术堆砌。

Rumelt《Good Strategy Bad Strategy》给出好战略的三要素：

1. **诊断（Diagnosis）**：问题的本质是什么
2. **指导方针（Guiding Policy）**：处理问题的整体方法
3 **连贯行动（Coherent Action）**：为执行指导方针设计的协同动作

缺任何一项 = 坏战略。

## 第二节 波特三大战略

Michael Porter 1996 年提出三大战略：

| 战略 | 核心 | 适用 |
|---|---|---|
| 成本领先（Cost Leadership） | 比对手成本低 | 规模型、标准化 |
| 差异化（Differentiation） | 比对手独特 | 高客单、用户愿付溢价 |
| 聚焦（Focus） | 服务特定细分群 | Niche 市场 |

L2 默认：**早期聚焦，成长期差异化，规模化后成本领先**。

错配的常见模式：

- 用聚焦做高客单市场（细分群付费密度低）
- 用差异化做同质化市场（用户不愿付溢价）
- 用成本领先做小批量定制（边际成本下不来）

## 第三节 SWOT 的边界

SWOT（Strengths / Weaknesses / Opportunities / Threats）是经典框架，但 L2 强调它的边界：

- **不诊断因果**：SWOT 只是列举，不分析为什么
- **不分主次**：把机会和威胁等同处理
- **不可被反驳**：列什么都说得通

L2 改良用法：

1. **Strengths / Weaknesses**：只列可被反驳的（如"我们的研发速度比对手快 2 倍"——可被实测反驳）
2. **Opportunities / Threats**：必须给"动作 + 时间窗口"
3. **交叉分析**：S+O = 增长杠杆、W+O = 抓住机会、T+S = 风险防御、W+T = 必避陷阱

## 第四节 BCG 矩阵的应用

BCG 矩阵（Growth-Share Matrix）把业务分成四类：

| | 高市场份额 | 低市场份额 |
|---|---|---|
| 高增长 | Star（明星） | Question Mark（问号） |
| 低增长 | Cash Cow（现金牛） | Dog（瘦狗） |

应用步骤：

1. 把当前业务按 BC 维度分类
2. 给每个业务一个现金流角色
3. 决定资源配置（明星优先、现金牛榨取、问号投入或放弃、瘦狗退出）

L2 经验：**多数一人公司只运营 1 个业务**——BCG 矩阵的价值在于判断"是否应进入第 2 个业务"。

## 第五节 Good Strategy / Bad Strategy 检验

Rumelt 提出坏战略的四类症状：

1. **空话（Fluff）**：用空洞词代替判断（"我们将追求卓越、拥抱创新、赋能客户"）
2. **不面对关键挑战（Failure to face the problem）**：绕开真正困难的问题
3. **目标当战略（Treating goals as strategy）**：把"成为行业第一"当战略，没说怎么做
4. **不良战略目标（Bad strategic objectives）**：目标之间互相矛盾

L2 自检清单：

- [ ] 我的战略能用一句话表达
- [ ] 我的诊断明确指出问题的本质
- [ ] 我的指导方针与诊断一致
- [ ] 我的连贯动作之间相互加强而非相互抵消
- [ ] 我的目标不是空话（不可量化即空话）

## 第六节 战略叙述的三层结构

战略叙述（L2 推荐格式）：

```
【战略一句话】
我们用【差异化能力】，服务于【细分群】，通过【盈利机制】获得【终局位置】。

【诊断】
当前最关键的问题是【X】。原因有 3：① ... ② ... ③ ...

【指导方针】
我们采取【波特三选一】，因为【理由 1+理由 2+理由 3】。

【连贯行动】
未来 18 个月我们做 3 件事：① ... ② ... ③ ...
```

写完后让团队 3 分钟内复述，能复述 = 战略清晰；不能复述 = 战略模糊。

## 第七节 战略与执行的连接

战略必须连接到执行：

- **战略 → OKR**：战略翻译成 1 个 O + 3-5 个 KR
- **OKR → 战术**：每个 KR 拆成 3-5 个战术
- **战术 → 行动**：每个战术拆成 3-5 个具体行动

L2 默认：**战略叙述每年更新一次，OKR 每季度更新，战术每月更新**。

## 第八节 常见战略陷阱

- **战略 = 愿景**：错。愿景是未来，战略是当前行动。
- **战略 = 资源堆砌**：错。战略是选择，资源堆砌是结果。
- **战略 = 模仿对手**：错。模仿出来的不是战略，是跟随。
- **战略 = 长期计划**：错。战略必须能解释未来 18 个月的具体选择。

## 常见证伪与坑

- **"波特过时了"**：错。波特三大战略在 2026 年仍是最清晰的战略分类之一。
- **"SWOT 没价值"**：错。SWOT 是入门工具，但必须改良使用。
- **"战略需要创新"**：错。战略需要的是选择，不是创新。

## 验收标准

学完本章，你应能：

1. 用一句话表达你的战略
2. 在波特三战略中选一种并解释
3. 用改良 SWOT 列出你的杠杆、风险与陷阱
4. 用 Rumelt 三要素自检你的战略
5. 把战略翻译成 1 个 O + 3 个 KR 的 18 个月路线图
