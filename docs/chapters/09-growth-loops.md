# 第 09 章 增长循环：四种引擎的选型与执行

> **能力对应**：growth-loops
> **学习目标**：能区分病毒循环、付费循环、内容循环、销售循环四类增长引擎并为产品选择一种主循环。

## 真实场景

一位创始人把"加 SEO"作为增长策略，6 个月没效果。问题不是 SEO 无效——是他的产品没有内容循环：没有用户生成内容、没有可索引的页面、没有自然外链增长。这就是典型的**没选对增长循环**。

## 为什么增长循环替代漏斗思维

漏斗（Funnel）思维：拉新 → 激活 → 留存 → 变现 → 推荐。漏斗是单向的，每一个环节都需要外部输入。

循环（Loop）思维：用户使用产品 → 输出某种资源 → 资源吸引新用户 → 新用户使用产品。循环是自我强化的，资源从内部产生。

L2 默认：**成熟产品用循环思维，导入期产品用漏斗思维**。两者不是互斥，是阶段切换。

## 第一节 四类增长循环

Reforge 框架把增长循环归为四类：

| 引擎 | 资源类型 | 例子 |
|---|---|---|
| 病毒循环 | 用户 | Slack 每邀请 1 人带来 X 人 |
| 付费循环 | 钱 | Google Ads 投 1 美元带来 X 美元收入 |
| 内容循环 | 内容 | YouTube 频道每发 1 视频带来 X 订阅 |
| 销售循环 | 关系 | B2B SaaS 每联系 1 客户带来 X 客户 |

L2 强调：**每个产品至少有一种主循环，可能有 1-2 个辅助循环**。

## 第二节 病毒循环的硬约束

病毒循环（Viral Loop）需要满足：

1. **可分享单元**：用户使用后产出的内容可分享（图片、链接、视频）
2. **可点击路径**：被分享者点击后能直接进入产品
3. **价值感知前置**：被分享者在未注册前就能感受到产品价值（预览、demo）
4. **激励闭环**：分享者获得回报（折扣、积分、声誉）

K 因子（每个用户带来多少新用户）公式：

```
K = 邀请数 × 邀请转化率
```

- K < 1：循环不增长，需要外部拉新
- K = 1：循环维稳，不扩大也不缩小
- K > 1：循环自增长，理论可指数扩张

实际罕见 K > 1 的产品，多数是 K ≈ 0.3-0.7。

## 第三节 付费循环的可计算性

付费循环（Paid Loop）的核心指标：

```
LTV/CAC = 付费收入 / 获客成本
```

LTV/CAC ≥ 3 时可以投；≥ 5 时可以激进投；< 1 时立即止损。

L2 默认：**付费循环只能在单位经济学跑通后启动**。早期常见错误是"用融资的钱烧付费循环"，一旦融资断档立刻死。

## 第四节 内容循环的耐心

内容循环（Content Loop）需要 6-18 个月才见效，但回报曲线最陡。

经典路径：

1. 创作者发内容 → 搜索引擎索引 → 用户搜索发现 → 点击进入 → 注册使用
2. 用户使用产品 → 产出内容 → 新创作者出现 → 重复

L2 默认：**内容循环必须和 SEO 同时做**，原因：SEO 是发现路径，内容是分享资源。两者结合才有网络效应。

不适合内容循环的情况：

- 客单 ≥ $5k 的 B2B（决策者不读 blog 决策）
- 决策周期 ≥ 6 个月的企业采购
- 一次性付费产品

## 第五节 销售循环的人力瓶颈

销售循环（Sales Loop）需要销售人员每联系 1 客户带来 X 客户。K 因子：

```
K_sales = 销售产能 × 转化率 × 平均客单
```

销售循环的天花板是销售人头数。一人公司无法跑大规模销售循环——除非客单 ≥ $10k。

L2 经验：**B2B SaaS 的销售循环在 100 客户前靠创始人，100-1000 客户靠 1-3 个 SDR，1000+ 客户靠 5-10 人销售团队**。

## 第六节 选主循环的决策树

按用户数阶段选主循环：

```
0-100 用户：创始人网络 + 行业社群（漏斗）
100-1000 用户：内容循环 + 病毒循环（双轮）
1000-10000 用户：付费循环 + 销售循环（双轮）
10000+ 用户：四轮并行
```

按业务类型选主循环：

| 业务类型 | 主循环 |
|---|---|
| B2B SaaS | 销售循环 |
| B2C App | 病毒循环 + 内容循环 |
| 内容平台 | 内容循环 + 病毒循环 |
| 电商 | 付费循环 + 内容循环 |

错配最常见的是 B2B SaaS 押病毒循环（客户决策链长，无分享动机）。

## 第七节 循环的可观测指标

每个循环必须有可观测代理指标：

- **病毒循环**：K 因子、邀请发送率、邀请点击率、新客病毒来源占比
- **付费循环**：CAC、LTV/CAC、各渠道 ROI
- **内容循环**：内容发布量、SEO 自然流量、内容触达新客占比
- **销售循环**：销售管线数、转化率、平均销售周期

L2 纪律：**每个循环必须有 1 个"先行指标"**——先行指标变动领先业务结果 1-2 周。

## 第八节 循环的终止条件

每个循环必须有明确的终止条件——什么时候这个循环不再有效？

- **病毒循环**：K 因子连续 3 个月 < 1 → 循环失效
- **付费循环**：LTV/CAC 连续 2 个月 < 3 → 循环失效
- **内容循环**：SEO 自然流量连续 3 个月 < 新客 30% → 循环失效
- **销售循环**：销售人效连续 2 季度下降 → 循环失效

L2 默认：**循环失效前必须设计下一个循环的 PoC**，否则增长断档。

## 常见证伪与坑

- **"四循环都要做"**：错。早期资源有限，只做 1 个主循环。
- **"病毒循环一定带来爆发"**：错。多数产品 K 因子 < 1，不能依赖病毒。
- **"付费循环一定亏"**：错。LTV/CAC > 3 时付费循环是稳态增长引擎。

## 验收标准

学完本章，你应能：

1. 识别你业务的潜在循环（病毒 / 付费 / 内容 / 销售）
2. 选定一种主循环并写出 90 天执行清单
3. 计算你的 K 因子（或销售管线 × 转化率）
4. 设定循环终止条件并指定替代循环
