# 第 03 章 商业模式：从画布到盈利机制

> **能力对应**：business-models
> **学习目标**：能复述商业模式画布 9 宫格、科斯交易成本理论、Teece 盈利机制，并为自己的生意选择模型并写一段"为什么是这个模型"的解释。

## 真实场景

一位创业者花 18 个月做了一款产品，月入 5000 元。他对人说"我做的是 SaaS"，但他的"客户"全是试用，从不付费；他的"价值主张"是为个人爱好者做的，付费意愿极弱；他的"渠道"是 Product Hunt + 一次登榜。他的问题不是产品差，而是**商业模式选错了**——他做的是交易型生意（个人爱好者买小工具），硬装成订阅型生意。

## 第一节 商业模式画布（Business Model Canvas）

9 宫格不是装饰，是用同一张图对齐团队对生意的理解。9 块：

| 区块 | 回答的问题 |
|---|---|
| 客户细分 | 我们在为谁解决 |
| 价值主张 | 我们用什么替他们解决 |
| 渠道 | 他们怎么发现我们 |
| 客户关系 | 我们怎么留住他们 |
| 收入流 | 他们为什么付钱、付多少 |
| 关键资源 | 我们必须有什么 |
| 关键活动 | 我们必须做什么 |
| 重要伙伴 | 谁帮我们做 |
| 成本结构 | 钱花在哪 |

L2 纪律：**每一格只允许一个具体句子**。"中小企业"必须改成"年收入 500 万 - 5000 万、有专职会计的制造业企业"；"通过社交媒体"必须改成"通过 LinkedIn 内容 + 微信社群"。

写不出句子的格子就是你的知识缺口。

## 第二节 科斯：为什么会有公司

1937 年科斯在《The Nature of the Firm》提出：市场交易有成本（搜索、谈判、签约、监督、违约），公司用内部协调替代市场交易。当内部协调成本 < 市场交易成本，公司就有存在意义；当内部协调成本 > 市场交易成本，公司就应该用市场（外包/平台/自由职业者）。

L2 应用：

- 你的"客户"是市场（每次独立谈判）还是公司（一次性签合同）？前者要算 CAC，后者要算销售周期。
- 你的"供应"是雇佣（内部协调）还是外包（市场交易）？前者固定成本高、扩展慢；后者弹性好、但服务质量波动。
- "一人公司"的本质：把尽可能多的环节外包出去，自己只保留边际收益最高的环节——通常是价值主张和客户关系。

一人公司不是"一个人做所有事"，而是"一个人负责不可外包的部分"。

## 第三节 Teece：盈利机制三选项

Teece 2010 年提出 Business Model ≠ Strategy。他把盈利机制拆成三个独立选项：

1. **No frill（最简产品）**：靠成本优势竞争。早期 Kindle、Great Wall Motor 都靠这一招。
2. **No swill（高质量差异化）**：靠客户愿付溢价。Apple、Notion 都属此类。
3. **Lock-in（生态锁定）**：靠切换成本竞争。Adobe、Salesforce 都靠这一招。

L2 应用：

- 一人公司通常只能选 No frill 或 No swill。Lock-in 需要生态和迁移成本，一人公司很难造。
- 选 No frill 的前提是成本曲线比对手陡（如 LLM 推理成本的指数下降让你能 1/10 价格提供同等质量翻译）。
- 选 No swill 的前提是用户能感知差异化（如面向独立设计师的发票工具在审美和工作流适配上明显好于通用工具）。

## 第四节 选型的硬规则

L2 列三条选型硬规则：

1. **客单价 ≤ $50 必选 No frill**：低客单用户对价格敏感，差异化他们感觉不到。
2. **客单价 ≥ $500 必选 No swill 或 Lock-in**：高客单用户决策周期长，他们要的是确定感，不是省 30%。
3. **不依赖平台规则的不要做 Lock-in**：Lock-in 必须有自有数据或工作流沉淀，建在别人平台上等于给房东做嫁衣。

错选模型最常见的后果是：用订阅模型做一次性生意（流失率高）、用交易模型做服务型生意（客单价低）、用免费模型做硬件型生意（融资撑不住）。

## 第五节 写一段 200 字的商业模式说明

写完画布 + 选型后，你必须能用 200 字把生意讲清楚。模板：

> 我们用【关键资源 + 关键活动】，通过【渠道】触达【客户细分】，交付【价值主张】并通过【客户关系】维护，与【重要伙伴】合作完成交付，收入来源于【收入流】，成本主要花在【成本结构】，选择【Teece 选项】作为盈利机制。一句话总结：这是为【人群】用【能力】解决【痛点】的【No frill/No swill/Lock-in】生意。

写不出 200 字说明 = 你的画布还有格子没填明白。

## 常见证伪与坑

- **"商业模式 = 收入模型"**：错。商业模式包含价值主张、渠道、客户关系、成本结构，收入只是其中一格。
- **"画布一次写完就完事"**：错。画布是动态文档，每个阶段都要重写。导入期靠口碑 → 增长期靠渠道 → 成熟期靠订阅，写法都不同。
- **"选最大市场 = 选对模式"**：错。Teece 三选项不互斥，但资源有限时只能选一个主选项。

## 验收标准

学完本章，你应能：

1. 填写完整 9 宫格画布，且每格都是具体句子
2. 用科斯理论解释你的生意为什么是"公司"而不是"市场"
3. 用 Teece 三选项为你的生意选定主选项并解释
4. 用 200 字模板把商业模式说清楚
