# 第 11 章 营收模型：订阅、交易、授权、广告与混合

> **能力对应**：revenue-models
> **学习目标**：能识别订阅、交易、授权、广告、混合五种营收模型并按行业基准选定主模型。

## 真实场景

一位创始人把订阅制（用户支付 9.99/月）套用到一次性工具（一个 Photoshop 插件）上——90% 用户注册免费试用但从不付费。因为 Photoshop 插件是"一次性解决问题"产品，订阅价值远低于一次性买断。这是典型的**营收模型错配**：用订阅模型卖交易型产品。

## 为什么营收模型是单位经济学的具体形态

单位经济学给的是数字，营收模型给的是"数字以什么形式兑现"。L2 把营收模型放在单位经济学之后是因为：必须先算清 LTV/CAC 才能决定哪个模型可承受 CAC。

## 第一节 五种营收模型

| 模型 | 收入形式 | 适用 |
|---|---|---|
| 订阅（Subscription） | 周期性付费 | SaaS、内容、会员 |
| 交易（Transaction） | 一次性付费 / 按次抽佣 | 电商、市场、应用商店 |
| 授权（License） | 永久买断 + 升级费 | 软件、游戏、IP |
| 广告（Advertising） | 流量变现 | 内容平台、社交 |
| 混合（Hybrid） | 多种组合 | 大型平台 |

L2 默认：**80% 收入来自 1 种主模型，20% 来自辅助**。

## 第二节 订阅模型的边界

订阅（SaaS、内容订阅）的优势：

- 现金流稳定（可预测）
- LTV 高（按时间累积）
- 估值溢价（投资人偏好）

订阅的边界：

- **用户期待持续价值**：订阅意味着用户期望"每月都有新东西"——内容订阅尤其如此
- **决策周期短**：用户随时取消，流失风险高
- **需要持续获客**：订阅流失意味着必须持续补新客

订阅的硬约束：

- **LTV/CAC ≥ 3** 才能投付费广告
- **GRR ≥ 85%** 才能跑付费循环
- **续约率 ≥ 70%** 才能扩大销售团队

## 第三节 交易模型的适用

交易（Transactional）的优势：

- 决策摩擦小（用户可一次付清）
- 现金流即时
- 适合低频高客单场景

交易的边界：

- **复购率低**：用户买一次后不再回来
- **LTV 难提升**：必须靠 AOV × 复购率
- **需要规模**：单笔毛利低，必须靠量

适用场景：

- 电商（Amazon、淘宝、Shopify）
- 应用商店（Apple App Store、Google Play 抽佣）
- 市场平台（Uber、Airbnb 抽佣）

L2 默认：**交易模型必须有 ≥ 1 个辅助收入（订阅、广告、增值服务）**，否则用户终身价值过低。

## 第四节 授权模型的现状

授权（License）传统上是软件主流模式（Microsoft Office、Adobe 早期），现在转向订阅为主。

授权仍适用的场景：

- **游戏单机 / DLC**
- **工业软件**（AutoCAD、Cadence）
- **IP 授权**（迪士尼角色、品牌）
- **企业一次性项目交付**

授权模型的关键：

- **升级费流**：从 v1 到 v2 的升级必须收费，否则单次买断后再无收入
- **维护费**：可叠加订阅式维护服务（很多传统 ERP 这么做）

L2 建议：**新业务优先订阅，不优先授权**。授权适合已有客户的存量市场，不适合增量市场。

## 第五节 广告模型的硬伤

广告（Advertising）的优势是用户付费门槛低，但有四个硬伤：

1. **依赖流量规模**：收入 = 流量 × CPM/CPC，单价低必须靠量
2. **依赖用户时长**：广告收入与使用时长强相关，时长短则收入低
3. **依赖广告主预算**：经济周期下行时广告主先砍预算
4. **依赖中介平台**：Google/Meta/字节 抽成 30-50%，流量主拿小头

广告适用的两类产品：

- **搜索引擎**（Google、百度）
- **内容平台**（YouTube、抖音、微信公众号）

L2 默认：**广告模型不作为主模型**，除非你的产品是上述两类之一。

## 第六节 混合模型的组合

混合（Hybrid）模型通常出现在已有规模的公司：

| 案例 | 混合模型 |
|---|---|
| Shopify | 订阅（基础费）+ 交易（GMV 抽佣） |
| Spotify | 订阅（Premium）+ 广告（免费版） |
| 微信 | 广告 + 交易（支付抽佣）+ 服务订阅 |
| 阿里 | 广告 + 交易 + 订阅（阿里云）+ 金融 |

混合模型的纪律：

- **每个模型独立核算 LTV/CAC**
- **每个模型独立团队负责**
- **避免相互 cannibalization**（订阅吃掉广告、免费版吃掉付费版）

L2 默认：**早期不要做混合**。混合是规模化的产物，不是规模化的起点。

## 第七节 营收模型的演进路径

L2 推荐营收模型按阶段演进：

```
导入期：交易（最低门槛）
  ↓
增长期：订阅（沉淀 LTV）
  ↓
成熟期：订阅 + 辅助（混合）
```

反例：导入期直接订阅 → 用户不付费 → 现金流断 → 死。

## 第八节 营收模型的可视化诊断

诊断当前营收模型健康度：

1. **收入分布图**：每月收入按模型分（饼图/堆叠柱状图）
2. **模型毛利图**：每个模型的毛利率对比
3. **模型增长图**：每个模型的环比增长
4. **依赖度图**：每个模型的客户占比与收入占比

L2 经验：**收入占比 > 60% 的模型是核心模型，< 20% 是辅助模型**。

## 常见证伪与坑

- **"订阅总是优于交易"**：错。低频高客单（如咨询、艺术品）订阅反而损失收入。
- **"广告是被动收入"**：错。广告需要持续投入内容和流量管理，并不被动。
- **"混合越多越好"**：错。混合增加运营复杂度，早期应聚焦 1 种主模型。

## 验收标准

学完本章，你应能：

1. 在五种模型中选一种主模型并解释为什么不偏离
2. 给出主模型的硬约束（LTV/CAC、GRR、续约率）
3. 画出当前收入分布图并标出每个模型的占比与毛利
4. 描述你业务的营收模型演进路径
