# 增长框架与局限

> AARRR 和北极星指标是**诊断与对齐装置**。把它们当战术操作系统，会系统性漏掉循环增长和战略权衡。

## AARRR 海盗指标（Dave McClure, 2007）

用户生命周期五段漏斗：

```
Acquisition 获客 → Activation 激活 → Retention 留存 → Revenue 收入 → Referral 推荐
```

用法：每段定义 1-2 个**比率型**指标，找出当前瓶颈段，集中资源攻一段（不是全线铺开）。

经典校准顺序是 **RARRA**（Retention → Activation → Referral → Revenue → Acquisition，GrowthHackers 共识）：留存没跑通之前投获客等于往漏桶里倒水。

## 北极星指标（North Star Metric）

一个最能捕捉"产品给用户创造的核心价值"的指标，全团队对齐用它。配套概念是 **input metrics**（可被团队直接影响的输入指标），形成 NSM → input 的因果树。

例：Airbnb 的 NSM 是"预订间夜数"，Spotify 是"总收听时长"（口径随战略演进，Amplitude 自述换过至少 3 次）。

## 已知局限（证伪清单）

### AARRR 的失效场景

| 局限 | 说明 |
|---|---|
| 单向漏斗无复利 | 底部产出（内容、口碑）无法回流顶部，模型里没有增长飞轮的位置 |
| 按层切团队 → 局部优化 | 营销团队冲获客注水，留存崩在下游；漏斗指标会奖励伤害整体的行为 |
| 阶段并非严格顺序 | 付费可能先于激活（先订阅后体验）；双边市场、市场型产品完全非线性 |

### 北极星指标的坑

| 坑 | 说明 |
|---|---|
| 虚荣/滞后指标不合格 | DAU、注册数、收入是结果不是价值代理；官方口径明确排除 |
| 古德哈特定律 | 指标一旦成为 KPI 就被博弈（刷时长、冲单量） |
| 单指标压不住复杂业务 | 双边市场（供需两端价值不同）、多产品线、多使用模式 |
| 与愿景冲突 | 愿景级决策（做难而正确的事）常在当期指标上是减分项 |

## 内容飞轮：漏斗之外的一种结构

对内容/社区/工具型产品，"生产 → 分发 → 回收 → 复盘"的循环结构比漏斗更贴切——每次循环的产出会成为下一轮的输入（内容沉淀、口碑、数据）。个人实践（生产→分发→回收→复盘的内容系统）的教训：

- **分发端要有数据回收**，否则循环断在"发了但不知道谁看了"
- 复盘要回到"下一轮生产什么"的决策上，否则只是报表

## 给自己的锚点

- 用 AARRR 前先回答：我的产品有回流结构吗？（内容/口碑/网络效应）有 → 先画飞轮再套漏斗
- 选北极星指标时做一次"博弈测试"：如果团队把这个指标做到极端，会做出什么伤害用户的事？答得出来 → 指标选错了
- 每个漏斗段只允许 1 个主指标 + 1 个反向护栏指标（guardrail：比如激活率上升但 7 日留存下降 = 假激活）
