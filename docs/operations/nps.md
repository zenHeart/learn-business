# NPS（Net Promoter Score）

> 迁移自 learn-operation `nps.md`，内容保持原意，仅整理格式与修正笔误。

## 概念定义

NPS 是净推荐值，反映产品给客户带来的感受与态度。

用户对产品评分，评分区间 0-10 分：**0 表示完全不可能推荐，10 表示非常有可能会推荐**。

不同分数段对应的用户群体：

- **0-6 贬损者**：使用不满意，没有忠诚度
- **7-8 被动者**：总体满意但并不热衷，会考虑竞争对手的产品
- **9-10 推荐者**：忠实用户，会继续购买产品并推荐给其他人

> **NPS = (推荐者数量 - 贬损者数量) / 总体样本数量**

NPS 指标分层：

- **< 0**：需要较大改进，否则难以生存
- **< 10**：存在较多不足，要尽快根据用户痛点优化迭代产品
- **≥ 30**：优秀的产品/服务，用户良好口碑可推动业务增长
- **≥ 50**：拥有高忠诚度用户

## 如何使用

1. **市场推广决策**：在产品投入市场推广前，先在已有客户中做 NPS 测试，当分数为正时，再投入更高的市场推广资源。
2. **通过追问搜集需求**：针对贬损者收集改进信息，驱动产品改进。
