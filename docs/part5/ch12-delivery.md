# ch12 交付与自动化

> **本章目标**：把"只有你能做的判断"和"谁都能做的执行"切开——前者保留在脑里，后者全部交给工具/AI/外包。掌握一人公司的标准工具栈（约 $20-50/月）、AI 替代率的真实区间（70-92%）、巴士测试标准，把"工作"变成"资产"。

## 真实场景

一个开发者独立做 SaaS 的真实工具栈：Next.js+TS 全栈 / Tailwind+shadcn / Supabase / Vercel / Stripe / Cursor+Claude Code。月基础设施成本 $20-50，单个 demo 从需求到上线最短 25 分钟-2 天——五年前同等能力的小团队至少 3 个月。**这是 AI 时代真正的杠杆：执行成本的塌陷让一个人的产出达到过去小团队的产能。**

## 成本结构的革命

2026 年被反复引用的对比（口径与来源见附录）：

| 项目 | 传统团队 | 一人 + AI | 降幅 |
|---|---|---|---|
| 年运营成本 | ~$22.5 万（5-15 人） | ~$1.8 万 | **-92%** |
| 开发 | 5 人技术团队 | 1 人 + AI Coding | -80% |
| 设计 | 全职设计师 | 1 人 + AI 生图 | -90% |
| 内容 | 3 人团队 | 1 人 + LLM | -85% |
| 客服 | 5 人团队 | Agent 机器人 | -95% |

中文一手访谈里 AI 的真实承担率：弹幕游戏美术 70%（链路：豆包→Banana→Triple3D→Blender→Mixamo）；生物技术 Agent 重复工作 80%；跨境电商运营 60%。**剩下的 20-30% 是判断、框架设计与客户沟通**——这正是 ch01 说的"为什么 AI 不能替代零基础者"的答案：行业认知+纠错能力是 AI 杠杆的前提。

## 一人的标准工具栈

被 2026 独立开发者社区固化的组合：

```
开发：Next.js + TypeScript（全栈统一）/ Nuxt / Python+Django
UI：Tailwind + shadcn/ui / UnoCSS
数据：Supabase（自带免费额度 Postgres+Auth）/ PlanetScale / PocketBase
部署：Vercel / Netlify / Cloudflare Pages
支付：Stripe（海外）/ 微信+支付宝（国内）；Paddle / LemonSqueezy（代缴税）
邮件：ConvertKit / Beehiiv / Substack
AI：Cursor / Claude Code / 豆包 / DeepSeek（按语言/任务）
分析：Plausible / PostHog（隐私友好）/ GA4
出海工具链（参考火山引擎独立开发者指南）：
  法律：iubenda（GDPR/CCPA 一键生成）/ Termly
  客服：Help Scout / Crisp
  i18n：i18next / Localazy
  行为：Hotjar（热图+会话回放）/ Amplitude / Mixpanel
  公司：Stripe Atlas / Firstbase（远程注册美/英/新加坡主体）
```

**选择原则不是"最好"，是最短路径 + 最低维护。** 每引入一个自运维组件（自建 DB / K8s），都在透支未来的时间。

## 巴士测试：自动化的验收标准

Levels 在 MAKE 里的标准：**你被公交车撞了，产品还能正常运行多久？**

- 收入型业务至少要过"周末测试"——48 小时不碰不崩
- 逐项排查：付款→交付（ch10 闭环）、常见问题自助（FAQ/机器人）、故障降级路径、月度账单自动对账
- 过不了巴士测试的业务 = 你买了一份不能请假的工作，不是资产（ch13 资产定义）

| 必过项 | 自查 |
|---|---|
| 自动交付 | 付款到交付全流程无人值守 |
| 自动计费 | 续费/失败重试/账单查询 |
| 自动支持 | 80% 问题 FAQ + 机器人过滤 |
| 自动监控 | 异常告警（如付费断崖）→ 你手机 |
| 故障降级 | 服务挂了给用户什么补救（退款/延长/人工兜底） |

## 什么不自动化

- **客户关系关键时刻**：首单欢迎、流失挽回、大客户投诉——AI 起草，你签名
- **产品方向决策**：数据回收可自动化，"下一版做什么"不能（ch11 + ch14）
- **内容的人格部分**：AI 可量产平庸内容，但受众跟随的是你（ch08 的"人格是差异化"）
- **质量红线场景**："需要实时监控 Agent 的工作进度与产出方向，防止偏离目标"（一手访谈原话）

## AI 协作的正确姿势

三个反模式：

1. **AI 当替身**：让 AI 直接生成最终内容/代码/回复 → 失去人格与判断，被 AI 平均水平拖累
2. **AI 当工具**：偶尔用一下 → 浪费它能给的杠杆
3. **AI 当技术合伙人**（最佳）：你判断+拆解+设定标准，AI 执行+量产+起草——**你负责方向与质量，AI 负责速度与覆盖**

实操流（产品功能开发）：

```
你：定义用户故事 + 验收标准 + 边界（做什么/不做什么）——10 分钟
AI：生成初版代码 + 测试 ——30 分钟
你：读 diff + 调整核心决策点 + 标注可优化方向 ——20 分钟
你+AI：迭代到通过验收 ——30-90 分钟
总耗时：约 2 小时 = 过去小团队一周
```

**关键反模式自检**：如果你的工作流里 AI 是"主角"，你的判断力会退化；如果 AI 是"工具"，你的杠杆太小。**AI 是放大器——放大正确判断，也放大错误判断。** 行业老手用 AI 是杠杆，新手用 AI 是加速犯错。

## 坑与证伪

| 坑 | 核查 |
|---|---|
| 全自动躺赚 | "被动收入"叙事反复被中位数打脸：MRR 中位 $145-500（附录）。自动化降的是交付成本，不是获客与信任成本 |
| 工具链越全越好 | 每个工具都是新的失效点+订阅成本。判断标准：工具替代的工时 > 维护它的工时才引入 |
| AI 替代一切 | AI 替代执行，不替代判断。"行业经验+AI ≈ 一人公司"，"零基础+AI ≠ 一人公司"——ch04 的回响 |
| 一次到位自动化 | 先手动跑通全流程（哪怕用表格+日历），再逐段替换。没跑过的流程没有自动化资格 |

## 小结

- 成本结构革命：年成本 -92%；AI 替代率 70-95% 取决于任务类型
- 标准栈 $20-50/月；选择原则是最短路径+最低维护，不是最强
- 巴士测试：你不在场时还能跑多久？五项必过
- AI 协作：你判断+拆解，AI 执行+量产；放大器既放大对也放大错
- 行业经验是 AI 杠杆的前提——零基础+AI 加速犯错
