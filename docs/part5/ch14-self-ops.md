# ch14 自我运营

> **本章目标**：建立"带自己"而不是"管理自己"的方法论——决策分型与判断力训练闭环、OKR 一人版、精力管理先于时间管理；识别判断力被代偿的信号并解代偿。这是 ch16 终局选择的前提，也是 ch01 三段论能跑满的最后一道工序。

## 真实场景

一位独立开发者每天"做正确的事"——回复客户、迭代功能、写内容。可到年底回看，发现自己花 60% 的时间在做 ch04 里"30% 的人在吐槽同一个痛点"对应的功能优化，而真正的增长杠杆（ch09 渠道与 ch08 受众）只用了 15% 的时间。**他不是不努力，是没有数据帮他做决策——一年下来还是凭"哪个最急"在分配精力。**

## 一人公司的真实瓶颈

不是小时数——是**高质量决策的次数**（每天 3-5 个是常见上限）。

应对：

- 唯一深度时段给创作/产品（早上第一件事，别给邮件）
- 减少决策数：固定例行动作（内容日更模板、固定定价、固定回复时段）——把意志力留给 ch04/ch15 级别的判断
- 每周留白半天：不排产。一人公司死于连续满负荷后的判断失准，不死于工作量不足

## OKR 一人版

目标用 SMART 校准（具体/可衡量/可达/相关/有时限），结果用金字塔原理拆解——**拆的是结果维度，不是执行路径**（按因果线或时间线拆出阶段结果）。

| 团队 OKR | 一人 OKR |
|---|---|
| 对齐工具（上下级拉齐） | 自我承诺装置（对抗自由职业的漂移） |
| 承诺型/愿景型分开 | 每季度 1 个承诺型就够（8/2 原则：80% 聚焦主线） |
| 复盘给上级 | 复盘给"上个月的自己"——写下来的预期 vs 实际 |

复盘四步：

```
回顾目标（当初意图/预期效果）
→ 评估结果（达成没？哪个 KR 拖了进度？）
→ 分析原因（预期 vs 实际差异）
→ 总结经验（下一轮改什么）
```

## 决策分型：判断力的日常训练

（ch01 已引入完整框架，这里回到实操）

| 决策类型 | 正确姿势 |
|---|---|
| 可逆 + 便宜 | 直接拍板，快速验证（**判断力的练习场**：改价格、改文案、发一篇内容） |
| 可逆 + 贵 | 小成本先导实验 |
| 不可逆 + 便宜 | 拍板 + 记录预期 + 事后复盘 |
| 不可逆 + 贵 | 数据 + 框架 + 找 3 个人挑战——最终仍是你署名拍板 |

训练闭环：**决策 → 事前写下预期（3 个月后应看到什么）→ 到期对照 → 偏差归因**。

偏差归因的三类（**只有第三类是真正的判断力训练素材**）：

- 信息不足：当时拿得到但没拿（流程问题，不是判断问题）
- 框架错误：维度想岔了（结构问题，不是判断问题）
- 判断失误：信息框架都对，选错了（**唯一真正的训练素材**）

## 判断力的代偿信号与解代偿

把"判断"外包给系统的行为模式（ch00 全文的主线问题）：

| 代偿信号 | 实质 | 解代偿 |
|---|---|---|
| 反复说"这不是拍脑袋排的" | 用评分替代判断 | 写反方最强论据；写不出=不敢署名 |
| 用 Rubric 把"做得好不好"量化 | 用打分代偿"哪个更好"的判断 | Rubric 服务的应是"讨论显式化"，不是"答案盖戳" |
| 每次决策都搜遍资料 | 用信息量掩盖判断 | 写决策日志的"如果 30 天后错了，赌什么"——找那个赌点 |
| 招高资历员工"补判断力" | 跳过自己练 | 自己不会做判断时再招人也只能外包判断 |
| 用 AI "让数据帮我决定" | 把权威转嫁 | AI 是放大器：放大正确判断，也放大错误判断 |


## 孤独与可持续

一人公司最大的隐性成本不是钱是**孤独**——没有同事的校验，判断的偏差会复利积累：

- 最低配置：一个 5-10 人的同路人群（月度互查对方的"决策预期"，互相当挑战者）
- 每季度一次"外部眼睛"：找一位同行为你的产品/定价/方向做无情评审（付费也值——这是买校验，不是买安慰）
- burnout 的预警信号：内容开始纯搬运、回复客户开始烦躁、对数据失去好奇——出现两条以上强制休一周

## 坑与证伪

| 坑 | 核查 |
|---|---|
| 用自律对抗一切 | 一人公司失败访谈里"自控差会比上班还辛苦"是高频原话。**解法是系统（固定例行、减少决策），不是意志力** |
| 7×24 全情投入 | 深度工作 4-5h/天已是一人公司实际上限。剩下是协作与执行。耐力赛：3 年 70 分 > 3 月 120 分 |
| 直觉决策=拍脑袋 | 直觉是内化的模式识别，只在有充分同类经验的领域可靠（Kahneman：环境规律 + 反馈质量） |
| OKR 太重 | 一人版每季度 2 小时定、每周 15 分钟对齐就够。做成仪式本身成了新坑 |
| 完美主义 | 数据驱动决策的纪律里写得清楚——**没有完美的决定，只有事后可复盘的勇敢尝试** |

## 小结

- 真实瓶颈是高质量决策数；固定例程释放意志力
- OKR 一人版：SMART + 承诺型 1 个 + 8/2 + 复盘四步
- 决策分型决定姿势；判断力训练闭环 = 预期 vs 实际 + 三类归因
- 代偿信号识别：把判断外包给系统的行为需要被反向追踪
- 孤独需要主动配置：互查小组 + 外部评审 + burnout 早期信号

## 思考题

> 1. 定你的"不可协商三件套"：深度时段 / 内容产出日 / 每周留白半天
> 2. 建决策日志（日期/决策/预期/到期日），从今天的第一个决策开始；一个月后回来做第一次判断力复盘

---

**验收标准**：

- [ ] 决策日志至少 30 条，可做第一次判断力复盘
- [ ] 不可协商三件套已设定并执行一个月
- [ ] 至少有 1 个 5-10 人互查小组或季度外部评审机制
