# ch14 自我运营

> **本章目标**：把"自我管理"翻译成一人公司版——决策分型（可逆性×成本）、OKR 简化、判断力训练闭环、精力管理、孤独治理。这是全书最私人的一章：你的身体、注意力、判断力是唯一稀缺资源。

## 真实场景

一个独立开发者的工作日记：上午连开 4 个会讨论定价方案；下午写产品代码；晚上回邮件；凌晨刷社媒看反馈。一周后身体疲惫但说不清做了什么关键事。**不是效率问题，是认知结构问题**——没区分哪些事该用深度时段，哪些事该批量，哪些事该完全外包。

## 决策分型：四象限与"可逆性优先"

一张图分清所有决策的处置方式（Amazon 的"双向门/单向门"框架，本书扩展为四象限）：

| 类型 | 处置 | 举例 |
|---|---|---|
| **可逆 + 便宜** | 直接拍板 | 改一句话文案、改一个定价、改一版产品方案——一周内能回滚就是"可逆" |
| **可逆 + 贵** | 小成本先导实验 | 投 $200 测试一个投放素材、做一个 5 天小样 |
| **不可逆 + 便宜** | 拍板 + 记录预期 + 复盘 | 报名学习、签约外包一次性项目 |
| **不可逆 + 贵** | 数据 + 框架 + 多人挑战 | 关一份全职工作、转型方向、卖公司 |

**核心：** 多数人把"不可逆+贵"当作"不可逆+便宜"来应对（用零数据拍板重大决定）——少数人把"可逆+便宜"当作"不可逆+贵"（因决策疲劳拖延改价）。**错位配错位，是失败的常见模式**。

判据自检：决策时问自己两件事："如果错了，我能多快回滚？"和"错了损失多少钱/时间？"——两个答不上来，按最严重档处理。

## 判断力训练：决策日志

ch01 提过判断力只能靠"决策→记录→复盘"长出来。决策日志结构：

```
日期：2026-09-02
决策：把订阅价格从 99/月改到 199/月
依据：转化率 12%，NPS 推荐者 60%；替代方案成本 ~$300/月
预期（3 个月后看）：付费用户减少 20%，但总收入 +30%，流失不增加
到期日：2026-12-02
实际：（到期填）
归因（信息不足/框架错误/判断失误）：（到期填）
```

**纪律：预期必须事前写。** 事后解释人人都是先知——事前预期是判断力训练的原料。

每月回头看归因分布：**判断失误 = 真正的训练素材**；信息不足（流程问题）和框架错误（维度问题）是另外两类的改进空间，不是判断力本身的进步。

### 警惕判断力代偿（ch01 反复警告）

反复说"这不是拍脑袋"并用评分系统/检索证据/外部审批替自己背书——这是判断力失能的代偿，不是判断力本身。**反方最强论点写不出来的判断，不值得署名。** 在按下按钮之前，写一句"反方最强会怎么反驳"——能写出来还在做，是判断；写不出就在回避。

## OKR 的一人版

OKR 不是仪式，是**承诺装置**——把"我飘到哪里是哪里"的工作状态固定到主线。

### 与团队版的差异

| 团队 OKR | 一人 OKR |
|---|---|
| 对齐工具（上下级拉齐） | 自我承诺装置（对抗自由职业的漂移） |
| 承诺型/愿景型分开 | 每季度 1 个承诺型足矣 |
| 复盘给上级 | 复盘给"上个月的自己" |

### 制定节奏

每季度花 2 小时定，每周 15 分钟对齐：

```
Q3 2026
承诺型 OKR：完成付费产品上线 + 50 个付费用户
  KR1：发布 1.0 版本
  KR2：100 个试用 → 50 付费（50% 转化）
  KR3：周内容更新 2 篇
复盘节奏：每周日 15 分钟
```

8/2 原则：80% 聚焦主线，20% 留给"看起来有意思但不是当前焦点"的实验。

## 精力管理：产能的真正瓶颈

不是小时数，是**高质量决策的次数**——每天 3-5 个是常见上限。

### 一日模板

```
05-09 深度时段（创作/产品/最难的事）
09-10 检查仪表盘 + 处理邮件（块状）
10-12 协作/会议（如果有）
13-14 深度时段
14-17 中等任务（运营/客户）
17-18 公开构建（社媒/内容——ch08）
18 后 学习/陪伴/陪伴自己（停止工作）
```

**纪律：** 每天唯一的"不可协商深度时段"是上午那段（你最清醒的时段）。把邮件、会议、消息安排到固定时段（不是实时响应）。

### 周节奏（已在 ch08/ch09 给出模板）

- 周一：规划（仪表盘 + 本周 3 个关键决策）
- 周三：半周复盘（调整计划）
- 周日：完整复盘（决策日志 + OKR 对齐 + 下周规划）
- **每周留白半天**：不排产。一人公司死于连续满负荷后的判断失准，不是死于工作量不足

## 决策疲劳的根源与对策

根源：意志力被当成无限资源。对策：**减少决策数 + 把决策批量到固定时间**。

| 反模式 | 对策 |
|---|---|
| 实时回邮件 | 每天 2 次（11:00 + 17:00），其他时间关 |
| 实时响应 IM | 设自动回复"我在专注工作，X 点回" |
| 内容选题每天想 | 周日定一周选题；写作时只执行 |
| 重复回答客户问题 | 写 FAQ + 模板回复（一次写，多次复用） |

## 孤独与可持续

一人公司最大的隐性成本是**孤独**——没人校验你的判断，偏差会复利积累：

- 5-10 人同路人群（**最低配置**），月度互查"决策预期"，互相当挑战者
- 每季度一次"外部眼睛"——找位同行做无情评审（付费也值：买校验不是买安慰）
- 必要时咨询教练/治疗师——判断力与情绪管理是同一件事的两面

### burnout 的预警信号（出现两条强制休一周）

- 内容开始纯搬运（创作枯竭）
- 回客户邮件开始烦躁（情绪能量耗竭）
- 对数据失去好奇（动力枯竭）
- 早晨醒来想"还要做这事"感到沉重（意义感流失）

## 坑与证伪

| 坑 | 核查 |
|---|---|
| 用自律对抗一切 | 一人公司访谈高频原话："自控能力差会比上班还辛苦"。解法是**系统**（固定例程、减少决策），不是意志力 |
| 7×24 全情投入 | 深度工作 4-5 小时/天是实际上限。耐力赛节奏 > 短期燃烧 |
| 直觉 = 拍脑袋 | 直觉是内化的模式识别，只在有充分同类经验的领域可靠（Kahneman 条件：环境规律+反馈质量）。新领域信数据 |
| OKR 太重 | 一人版 2 小时/季度 + 15 分钟/周就够；做成仪式本身成为新坑 |
| 团队管理经验套自己 | 一人公司是"带自己"，不是"管 0 个员工"——管理章节的方法论不能直接套用（附录保留过渡读物） |

## 小结

- 决策分型四象限：可逆/不可逆 × 便宜/贵；错位配错位是常见失败模式
- 判断力训练闭环：决策 → 事前写预期 → 到期复盘 → 归因（信息/框架/判断）
- OKR 是承诺装置不是仪式；一人版 2 小时/季度 + 15 分钟/周
- 精力瓶颈是高质量决策次数（每天 3-5 个），不是小时数
- 系统对抗倦怠：固定例程 + 减少决策 + 每周留白 + 同路人群

## 思考题

> 1. 用决策分型评估你本周做的 5 个决策：分别属于哪个象限？有没有错位（把可逆当不可逆/反之）？
> 2. 建立决策日志（哪怕只是 Notion 一张表），从今天的第一个决策开始写。一个月后看归因分布。
