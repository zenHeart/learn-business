# ch13 财务与法务

> **本章目标**：把财务当工具不当压力——能读懂自己的现金流表、单位经济、税负合规；建立公私账户防火墙；按收入阶段选择主体形态（中国语境）；把"一生资产"的视角落到"我每年实际拥有什么"上。

## 真实场景

一位独立开发者年收入 60 万，发现"自己根本不知道赚了多少"。他每月收到平台代扣的钱和个人账户收款混在一起，没记账，没算通道费，没留应急储备——直到银行卡里突然扣了一笔 3 万的税（个人所得税补缴），才知道合规与现金流必须一开始就做。**不是收入越高越好，是"知道赚多少、留多少、欠多少"才稳**。

## 商业语法：资产与负债

商业世界的基础二分法（整理自《穷爸爸富爸爸》笔记）：

- **资产**：无需你持续投入、能产生收入或有增值潜力且流动性好的东西
- **负债**：持续把钱从你口袋拿走的东西

容易误判：**自住房不是资产**（持续产生维护/税费且不产生收入）——这是该书最具争议也最有启发的视角；**需要你全职投入的"生意"是工作不是资产**（对照 ch12 巴士测试——过不了就是你的另一份工）。

一人公司的资产化路径：卖时间 → 卖产品 → 卖系统 → 卖品牌/受众。每上一级，"你不在场时的收入占比"上升（ch12 自动化的本质就是这条路径的执行）。

## 财商四柱

| 柱 | 内容 | 一人公司场景 |
|---|---|---|
| 财务知识 | 阅读理解数字 | 看懂自己的三张表（现金流、单位经济、税负） |
| 投资策略 | 以钱生钱 | 利润的去向：再投入 / 金融资产 / 现金储备 |

> 态度基准：**在游戏规则之内创造财富**——理解规则不是钻空子，是知道边界在哪。

## 现金流纪律

一人公司的现金流安全线（经验规则，非审计标准）：

- **6-12 个月生活费**的现金储备才考虑全职投入——对冲"52.7% 月入<7000"的中位数现实
- 个人与业务账户分离从第一天开始——混同的代价不只是税务风险，还有算不清的真实盈利
- 月度三张数（5 分钟填，不手填就自动化）：

```
收入（按渠道分）：SaaS / 一次性 / 服务 / 赞助
成本（按类分）：AI 订阅 / 基础设施 / 外包 / 通道费 / 税
净现金流：收入 − 成本
```

通道费被严重低估：弹幕游戏案例平台抽 50% + 主播分成 42%，开发者仅剩 ~8%。**签约前算清全链路费率**——不是月入多少，而是"我能拿到多少"。

## 主体与税务（中国语境）

一人商业化的主体阶梯：

| 阶段 | 形态 | 适用 |
|---|---|---|
| 起步 | 个人（平台代扣/劳务报酬） | 副业验证期，零成本 |
| 增长 | 个体工商户 | 定期有收入、开票需求；部分地区核定征收税负显著更低 |
| 规模化 | 一人有限公司（OPC） | 高收入、需要有限责任防火墙、签约大客户 |

**核心事实**：
- 注册本身免费；记账代理约 2000 元/年（中文一手访谈口径）
- 有限责任是法务防火墙的核心：公私账户严格分开、合同主体明确——**混同会击穿有限责任**，这不是细节
- 杭州上城区（"未来数智港" OPC 社区）、广东等地的 OPC 专项政策（公开报道：上城区年度 1 亿元专项资金 + 10 亿元基金 + 免费工位 + 算力券）说明**政策在主动降低这条路**的成本——查你所在城市（C4 报道）
- 出海：海外主体或用 Paddle/LemonSqueezy（Merchant of Record 代缴税）

## 单位经济（一道算术题）

ch11 的关键公式在这里落地到现金：

```
单位经济 = ARPU − 单客变动成本 − CAC
```

```
LTV = ARPU × 订阅时长 = ARPU / 月流失率
LTV/CAC = 健康度（>3 健康，<1 烧钱）
CAC 回收期 = CAC / (ARPU × 毛利率) ≤ 12 个月
```

判据：**LTV/CAC > 3 + CAC 回收期 ≤ 12 个月**——这是 SaaS 通行的健康线，达不到之前不要投放获客（ch09 的前置条件不是空话）。

## 财务报表的最小集

一人公司不需要会计资格证，看懂这三张就行：

1. **利润表（monthly P&L）**：收入 - 变动成本 - 固定成本 = 净利润。一人公司主要看月度同比/环比
2. **现金流表（cash flow）**：钱从哪来（收款）、到哪去（付款）。和利润的区别：**没收到钱的销售不算收入**（订阅订阅未确认收入按权责发生制算，看你怎么处理）
3. **资产负债表（balance sheet）**：资产（现金/订阅者/产品代码/品牌），负债（应付/客户预付），权益（净资产）。一人公司主体形态上升后看

记账工具：国内市场用随手记/专业会计师代理；出海用 QuickBooks/Xero，或 Wave（小型免费）。

## 坑与证伪

| 坑 | 核查 |
|---|---|
| "收入=利润" | 通道费能吃掉大半。签约前算清费率（不是"月入多少"，是"我能拿多少"） |
| 一开始就注册公司 | 主体形态跟着收入走。验证期零收入时养公司是纯成本；高收入后还用个人收款是税务风险 |
| 个人与业务账户混用 | 税局、合伙人、银行——任何一方要求看账时混账是致命的 |
| 收入高了就融资 | 一人公司融资天然困难（个人信用替代企业信用）。走自营现金流路线（ch15） |
| 复盘看总盘不看单位 | 月入 5 万看着不错，但用户 CAC 800、单客 LTV 600 → **每一单亏 200**——看总额永远发现不了 |

## 小结

- 资产 / 负债 = 商业世界的基础语法；产品化阶梯每上一级你不在场时收入占比上升
- 现金流安全线：6-12 个月储备 + 公私账户分离 + 月度三张数
- 主体形态跟着收入走；高收入后再注册公司，否则税务风险
- 单位经济 LTV/CAC > 3、CAC 回收期 ≤ 12 月是投放获客的硬前置
- 财务报表最小集：利润表/现金流表/资产负债表——月度先做现金流表
