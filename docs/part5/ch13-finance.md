# ch13 财务与法务

> **本章目标**：建立一人公司的财务与法务最小工作框架——理解资产/负债的生意思维（不是会计科目）；掌握主体形态阶梯（个人→个体工商户→一人公司）；做好个人与公司账户隔离；建立现金流安全线。ch01 的理论在这里落地为日常动作。

## 真实场景

一个独立开发者月收入稳定 $8k，开始认真考虑要不要注册公司。**问题不在要不要——在于什么时候、用什么形态、配套做什么**。盲目注册会白交几千代理费；不注册又踩税务与个人风险。本章帮你把这事拆成可决策的步骤。

## 资产的生意思维：先懂，再选

ch01 提过商业世界的二分法（整理自《穷爸爸富爸爸》）。这里把它落到一人公司的日常：

```
资产：无需你持续投入、能产生收入或有增值潜力且流动性好的东西
负债：持续把钱从你口袋拿走的东西
```

清单对照（一人公司版）：

| 项目 | 性质 | 测试 |
|---|---|---|
| 已订阅 SaaS 的客户名单 | **资产** | 每月自动续费，无需你动手 |
| 还在维护但没人用的产品 | **负债** | 每月托管费，没收入 |
| 稳定付费的邮件列表 | **资产** | 月均产出 $X（按 §X 法则） |
| 外包付出去的服务包 | 中性 | 看每外包一笔是否让你时薪提升 |
| 全职投入的"生意" | **工作不是资产** | 它绑住你了，过不了巴士测试 |

一个直觉测试（来自《穷爸爸》）：**"我不在场时它还能产生收入吗？"** 不能 → 不是资产，是你的另一份工作。

一人公司的资产化路径（从 ① 到 ④ 越来越多人不是资产）：

```
收入（卖时间）→ 产品（卖复制品）→ 系统（自运行）→ 品牌/受众（可迁移的信任）
```

每上一级，"你不在场时的收入占比"上升。多数一人公司死在 ①，把目标放在 ③。

## 主体形态阶梯（中国语境）

| 阶段 | 形态 | 适用 | 注册成本 |
|---|---|---|---|
| 起步 | 个人（平台代扣/劳务报酬） | 副业验证期，月入<5000 | 0 |
| 增长 | 个体工商户 | 定期收入+开票需求；部分地区核定征收税负显著更低 | 0-几百 |
| 规模化 | **一人有限公司（OPC）** | 高收入，需要有限责任防火墙 | 0（记账代理 ~2000 元/年） |

三个事实，决定你的形态选择：

1. **有限责任是核心价值**：公司债务不穿透到个人财产——前提是公私账户严格分开、账目独立核算（混同会击穿有限责任）
2. **杭州/广东/宁波/上海等地的 OPC 政策**：年度 1 亿元专项资金、免费工位、算力券——政策在主动降低 OPC 的启动成本，**值得查你所在城市的同类政策**
3. **OPC 融资天然困难**：单一股东 = 个人信用替代企业信用，抗风险能力弱于团队公司。想融资就别走这条路（ch16 终局会展开）

### 出海主体的特殊处理

出海产品常用路径：
- **Delaware C-Corp + Stripe Atlas**（美元收入 + 未来融资预期）
- **英国 Ltd / 新加坡 Pte Ltd**（税务友好 + 银行开户便利）
- **Merchants of Record（Paddle / LemonSqueezy）**——你不用注册海外主体，平台代收款代缴税，**适合起步期最快路径**

## 财务动作清单

### 个人与公司账户

- 公私账户从第一天分离——混同的代价不是税务罚款，是无法分清真实盈利，无法做单位经济（ch11）
- 推荐结构：1 张个人卡（生活） + 1 张个人卡（业务收入暂存） + 公司账户（收入直接进公司） + 公司卡（支出）

### 现金流安全线

经验规则（不是审计标准，但被反复验证）：

- **6-12 个月生活费现金储备**才考虑全职投入（对冲"52.7% 月入<7000"中位数现实——ch11 现金跑道）
- 每周/每月三张数：**收入（分渠道）**、**成本（分：AI 订阅/基础设施/外包/税务）**、**净现金流**
- 用 ch12 的自动化跑报表，不手填

### 单位经济与盈亏平衡点

```
盈亏平衡月数 = 当前固定成本 ÷（客单价 × 月均付费用户 − 变动成本）
```

更简单的版本：算一个付费用户给你贡献多少毛利，乘以每月新付费用户，得到每月净增收入——直到累计覆盖固定成本。这是"我能不能全职"和"还需要多少月"的回答。

### 税务基本盘

- 起步期个人形式：劳务报酬，按月预扣预缴（平台代付时已扣）
- 个体工商户/一人公司：增值税（小规模纳税人）+ 企业所得税/个人所得税（经营所得）
- **具体节税/合规务必找当地代理记账 + 税务师**——框架是免费的，专业意见是要付费的

## 法务防火墙

### 必备基础

- **隐私政策 + 服务条款**：用 iubenda/Termly 一键生成（GDPR/CCPA 等多地区适用）；自己写有法律风险
- **退款政策**：ch10 把它当风险逆转；同样要在落地页/合同明确写出
- **合同模板**：客户合同、外包合同、合作协议——找律师审一份模板，多次复用

### 知识产权与个人品牌

- **个人名字 + 品牌商标**：年营业额到 7 位数时及时注册；2025 年个人商标申请量涨 34%
- **域名 + 社交账号**：尽量全平台同名；你的名字就是品牌（ch08）
- **平台归属**：平台账号不是你的（条款：广泛许可），**邮件列表 + 独立站才是你真正拥有的资产**（ch08 重申）

### 责任隔离

- 一人公司的"有限责任"前提：**公私严格分开 + 不欺诈 + 正常决策流程**
- 高风险业务（涉及人身健康/资金）建议配专业责任保险
- 与客户/供应商的合同里加合理的责任上限条款

## 坑与证伪

| 坑 | 核查 |
|---|---|
| "一开始就注册公司" | 主体跟着收入走。验证期零收入养公司是纯成本；高收入还用个人收款是税务风险 |
| 收钱全进个人卡 | 起步期可，但到一定规模（看当地税务师建议）必须分离；混同→击穿有限责任 |
| 《穷爸爸富爸爸》全盘照收 | 框架（资产负债二分、财商四柱）有持久价值；具体投资建议（房地产套利）绑定时代环境，被批幸存者偏差。**取框架不抄操作** |
| 自己写隐私政策 | GDPR/CCPA 处罚是真罚。模板服务几十到几百美元，比律师便宜得多 |
| "没收入不算创业不需要注册" | 收入≠利润，平台/广告/联盟分成也算应税。报税比办公司便宜（合理节税比逃税便宜） |
| 信任危险品 | 客户数据丢失/泄露 = 公司责任 + 个人责任。最小成本保护：基本加密 + 备份 + 不收集不需要的数据 |

## 小结

- 资产 = 不在场也能产生收入的东西；一人公司目标从卖时间 → 系统 → 受众的资产化路径
- 主体形态阶梯：个人→个体户→一人有限公司，按收入与风险选
- 公私账户第一天就分离；6-12 月生活储备才考虑全职
- 法务最小集：隐私政策（模板生成）+ 退款政策 + 合同模板 + 商标（到一定规模）
- 框架（资产/负债二分）取用，**不抄操作**（书的具体投资建议有时代局限）
