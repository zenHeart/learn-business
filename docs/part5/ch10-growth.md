# ch10 增长

> 一人公司的增长不是"做大"，是**加杠杆不加人**：同样的你，撬动更大的价值流。先想清楚增长的结构，再选杠杆。

## 先校准：增长的分布现实

Indie Hackers 用收入阶梯当里程碑：首笔收入 → $1k MRR → $10k MRR。分布数据（Stripe 核验样本 + TrustMRR）：

```
有收入的独立产品：MRR 中位 $145-500
能过 $10k MRR：约 3-6%
中位与头部之间隔着两个数量级
```

这组数字的用法不是劝退，是**定位**：从 $145 到 $1k 靠执行，从 $1k 到 $10k 靠结构（本节），$10k 往上靠复利和运气（ch11 决定要不要继续）。每一段的打法不同，混用是常见失败原因——用 $10k 阶段的打法（雇人、投放）打 $500 阶段的仗，烧死在到达之前。

## 增长的四种杠杆（按不雇人优先级）

### 1. 产品杠杆：让产品自己获客

- **内置传播**：产出物带署名/水印（Notion 模板、"用 X 制作"角标）——用户的每次使用都是展示
- **SEO**：工具型产品的自然流量复利（Levels 的组合主打法：AI 生成内容 + 自动化客服 + SEO 获客）。内容页 = 长期资产，发布日流量 = 租来的流量
- **集成市场**：上架平台生态（Slack/Chrome/飞书/Notion 集录）借平台分发

### 2. 内容杠杆：受众的复利

ch5 的飞轮进入复利区的标志：老内容持续带来订阅/咨询（存量内容开始工作，你不再为流量逐篇付费）。此时增长动作只有两个：提高回收精度（哪类内容带转化）、复制已验证的内容形态。

### 3. 价格杠杆：最便宜的增长

转化率不变，客单价 × 2 = 收入 × 2（ch4 的涨价纪律）。加高档位、年度订阅（一次性收 10 个月价格换现金流）、企业定制档——都是不开发新功能的"增长"。

### 4. 组合杠杆：Small Bets

Daniel Vassallo 的路线（2019-2024 年收 $33k→$620k，自报）：**同时押多个小赌注，砍掉不工作的，加倍工作的**。与 Marc Lou 的 21-12 模式同构。纪律：

- 每个 bet 有固定的小预算（时间/金钱封顶）
- 预设止损线（事前写，防事后合理化——ch2 同款纪律）
- 赢家加注的标准是数据不是感情

## 增长模型与它们的局限

AARRR（获客→激活→留存→收入→推荐）是最常用的诊断框架，**已知局限**：单向漏斗无复利（底部产出不能回流顶部）、按层切团队导致局部优化（灌水获客+留存崩）、阶段并非严格顺序（双边市场非线性）。配套校准顺序 RARRA：**留存没跑通之前，不投获客**——往漏桶倒水是一人公司最贵的错误。

北极星指标（一个最能代表用户价值的指标）用于对齐，**已知坑**：虚荣指标不合格（DAU/注册数）、指标一旦考核就被博弈（古德哈特定律）、单指标压不住多边业务。护栏指标必须配对出现（激活率↑ 但 7 日留存↓ = 假激活）。

## 坑与证伪

| 坑 | 事实 |
|---|---|
| 增长黑客速成 | 增长是结构的产物：留存×转化×传播的结构没搭好之前，"黑客技巧"只是往漏桶倒水的不同姿势 |
| 投放买量 | CAC 在没有留存数据时是盲注。一人公司先榨干免费杠杆（SEO/受众/传播内置）再考虑付费 |
| 什么都自己做 | 增长阶段可以买回时间：剪辑/设计/初稿外包，判断保留。外包的是执行杠杆，不是判断 |
| 收入停滞=加产品 | 先查结构（定价？留存？受众匹配？）再加数量。结构问题的加法只会稀释——52.7% 月入<7000 的样本里，大量是"多个平庸产品"的叠加 |
