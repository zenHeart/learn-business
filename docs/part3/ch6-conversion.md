# ch6 转化

> 流量 × 转化率 × 客单价 = 收入。三个乘数里，转化率是一人公司最能自主改善的一个——它不需要预算，只需要理解人。

## 转化率的真实基准

先校准预期（两个口径并陈，详见附录）：

| 口径 | 数字 | 样本 |
|---|---|---|
| Unbounce 2024（官方报告） | 全行业中位 **6.6%** | 4.1 万落地页 / 5700 万次转化（含点击、表单，**不含付费**） |
| WordStream（行业基准） | 均值 **2.35%**，Top 10% **11.45%+** | 广告落地页 |
| B2B SaaS（细分） | 自助注册页 4-10%，Demo 申请页 1.5-4% | 行业基准汇总 |
| 免费→付费 | freemium 中位 **8%**（好 3-5%、优 8-12%）；要卡试用约 **30%** | ChartMogul 2026, n=200 |

三个使用纪律：

1. **别拿 6.6% 当付费预期**——它含表单点击；从访问到付费，整体 1-3% 已是健康水平
2. 低流量阶段（<1000 UV/月）的转化率无统计意义，先解决流量再优化转化
3. 转化率异常高（>15%）不是喜事——多半是流量太窄（都是熟人）或定价太低

## 落地页转化结构

高转化落地页的共同骨架（从上到下）：

```
① 痛点共鸣句——用户原话（ch1 收集的吐槽）
② 解决方案一句话 + 差异化（为什么不是别家）
③ 社会证明——用户结果/数字/推荐语（比 logo 有用）
④ 价格锚与三档（ch4）
⑤ 风险逆转——退款保证/免费试用
⑥ FAQ——把犹豫对象化
⑦ 行动按钮——动词+结果（"开始免费生成"优于"注册"）
```

每屏一个任务，删除一切不服务转化目标的链接（包括导航栏）。

### 信任的四个来源

没有品牌背书的一人公司，信任从哪来：**公开构建**（build in public——把过程数据公开）、**真实案例**（用户结果，哪怕只有一个）、**人格一致性**（长期内容积累，见 ch5）、**风险逆转**（退款保证，用条款替代品牌）。

## 支付与交付闭环

转化漏斗的最后一段经常被忽视：

- **支付摩擦**：每多一步跳转流失 10%+；能内嵌就不跳转，能扫码就不填表单
- **支付方式匹配市场**：海外 Stripe/Paddle（Paddle 兼做税务合规），国内微信/支付宝个人码起步即可、量大再上商户
- **自动交付**：付款 → 交付应该无人值守（自动发卡/开权限/发邮件）。凌晨 3 点的订单也需要即时满足

## 坑与证伪

| 坑 | 事实 |
|---|---|
| A/B 测试一切 | 低流量下 A/B 是噪音放大器（<1000 转化/月的差异基本不可判定）。低流量阶段用定性访谈 + 大改动（整页重构）代替小改动测试 |
| 转化率崇拜 | 转化率 × 客单价才是收入。99% 转化率 × 客单 0 = 0。先保定价（ch4）再优化转化 |
| 弹窗轰炸 | 首屏 3 秒弹订阅框的流失 > 收益；退出意图弹窗是底线位置 |
| "注册"按钮文案 | 动词+结果（"免费生成第一份报告"）比抽象 CTA（"注册/开始"）稳定更优——行业共识级实践 |
