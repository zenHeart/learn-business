# ch5 受众

> 受众优先（audience-first）：先有听你说话的一群人，再决定卖什么给他们。顺序反过来（先产品后找人）是一人公司失败率最高的路径。

## 为什么受众先于产品

产品需要流量才有人买，流量需要信任才转化，信任需要时间积累。**三者中只有信任无法用钱快速买到**——所以它应该最先开始建设。

Justin Welsh 的模式是这个逻辑的极致样本：一人、无团队、无广告投放，靠 LinkedIn/邮件列表的受众资产做到年入 $415 万（2024，自报）→ $283 万（2025，自报，约 91% 毛利）。他的"产品"（课程）是受众的函数，不是独立变量。

中文侧同构的模式：AI 训练营博主（公众号 20 万粉 → 单期 6000 元 × 每月 2 期）；"小山闭门会"社群；AI 短剧作者先在 B 站积累曝光再接商单。**受众是渠道，内容是获客，产品是变现**——顺序不能乱。

## 内容飞轮

```
生产（你的实践/ Know-how）
  → 分发（选 1 个主平台 + 1-2 个同步渠道）
    → 回收（数据：哪类内容带来咨询/订阅/购买）
      → 复盘（下一轮生产什么）
        ↺ 产出回流为下一轮的素材（案例、口碑、数据）
```

纪律三条：

1. **主平台只选一个**（你的目标用户真在的地方），其他渠道是同步不是运营
2. **分发端必须有数据回收**——发了但不知道谁看了、看完了做了什么，飞轮就断在中间
3. **复盘落到"下一轮生产什么"的决策**，否则只是报表

## 邮件列表：一人公司最重要的资产

社交平台的粉丝是"租来的"（算法改一次归零），邮件订阅是"自己的"。行业经验法则是**每个订阅者每月值 $1**——注意两个修正：

- 这是从业经验法则，非普查数据；广告型 newsletter 实测中位约 **$0.15-0.50/订阅者/月**（低 2-7 倍）
- 高信任、窄利基的名单可以远高于 $1（你卖 $600 训练营，1000 个铁粉名单一个月转化 2% 就是 $12k）

所以列表的价值不在规模在**匹配度与信任**：1000 个精准订阅 > 10000 个泛粉。

### NPS：受众质量的温度计

定期对付费用户做 NPS 测评（0-10 分：0-6 贬损者 / 7-8 被动者 / 9-10 推荐者；NPS = 推荐者% - 贬损者%）：

- **< 0**：产品要较大改进，先别投获客
- **≥ 30**：优秀，口碑可以推动增长，才值得加大分发投入
- 推广前先测 NPS（分数为正再投资源），贬损者的追问是最便宜的需求调研

> NPS 详细分群与用法见[原运营章合并内容](#nps-快速参考)。

## 坑与证伪

| 坑 | 事实 |
|---|---|
| 全平台铺开 | 一人精力只够一个主平台。全铺 = 全部平庸。多账号同步用工具，不做运营 |
| 追粉丝数 | 粉丝是租来的且与收入弱相关；订阅数与精准度才是资产。对标 Justin Welsh 的 91% 毛利，不是粉丝数 |
| "先做产品，发了自然有人买" | 没有受众的新产品，发布日=沉默日。冷启动的正确顺序：先建名单（哪怕 50 人），再发布 |
| 内容只发广告 | 内容提供价值（Know-how 复盘），产品是自然延伸。广告占比 > 30% 信任开始折旧 |

## NPS 快速参考

- **0-6 贬损者**（不满意、无忠诚度）/ **7-8 被动者**（满意但不热衷，会被竞品带走）/ **9-10 推荐者**（忠实，会复购并推荐）
- **NPS = (推荐者数 − 贬损者数) / 总样本数 × 100%**；分层：<0 需大改、<10 尽快按痛点迭代、≥30 优秀、≥50 高忠诚
- 用法：投放前测试（分数为正再加大投入）+ 对贬损者追问收集改进信息
