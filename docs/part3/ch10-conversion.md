# ch10 转化与销售

> **本章目标**：理解转化率的真实基准（双口径）与影响因素；掌握高转化落地页的七段结构；跑通支付到交付的无人值守闭环；学会一人公司的销售对话。推广把人带来（ch09），这一章让他们掏钱。

## 真实场景

同一个产品页，改了三处：第一行从产品介绍改成用户痛点原话；价格从"¥99/月"改成三档表（推荐档预高亮）；"注册"按钮改成"免费生成第一份报告"。两周后，同样流量下试用申请从月 12 个涨到 41 个。**转化率不是玄学，是页面结构与信任建设的函数。**

## 转化率的真实基准

先校准预期（双口径并陈，口径差异必须知道）：

| 口径 | 数字 | 说明 |
|---|---|---|
| Unbounce 2024（官方） | 全行业中位 **6.6%** | 4.1 万页样本；**含点击/表单，不含付费** |
| WordStream（行业基准） | 均值 **2.35%**，Top 10% **11.45%+** | 广告落地页 |
| B2B SaaS 细分 | 自助注册 4-10%；Demo 申请 1.5-4% | 行业汇总 |
| 免费→付费 | freemium 中位 **8%**；**要卡试用 ~30%** | ChartMogul 2026, n=200 |

三条使用纪律：

1. **别拿 6.6% 当付费预期**——从访问到付费，整体 1-3% 已属健康
2. 低流量（<1000 UV/月）阶段转化率**没有统计意义**——先解决流量（ch09），再优化转化
3. 转化率异常高（>15%）不是喜事：流量太窄（都是熟人）或定价太低（ch07 涨价信号）

## 落地页：七段转化结构

高转化落地页的共同骨架（从上到下，每屏一个任务）：

```
① 痛点共鸣句 —— 用户原话（ch04 访谈收集的，不是你改写的）
② 解决方案一句话 + 差异化 —— ch05 定位公式 + "为什么不是别家"
③ 社会证明 —— 用户结果/数字/推荐语（1 个真案例 > 10 个 logo）
④ 价格锚 —— 三档表（ch07）
⑤ 风险逆转 —— 退款保证 / 免费试用（用条款替代品牌信任）
⑥ FAQ —— 把犹豫对象化（销售对话里被问 3 次以上的问题）
⑦ 行动按钮 —— 动词+结果："免费生成第一份报告" 优于 "注册"
```

删掉一切不服务转化的链接——包括导航栏（给用户离开的每一个理由都是漏桶上的洞）。

### 信任的四个来源

没有品牌的一人公司，信任从哪来：

| 来源 | 做法 |
|---|---|
| 公开构建 | 过程数据公开（收入/决策/失败）——ch09 |
| 真实案例 | 用户结果（哪怕只有一个），带可验证细节 |
| 人格一致 | 长期内容积累（ch08）——人格是你和平台的差异化 |
| 风险逆转 | 退款保证/免费额度：用合同条款替你承担初次信任成本 |

## 支付与交付闭环

漏斗最后一段最常被忽视（工程视角的盲区）：

- **支付摩擦**：每多一步跳转流失 10%+。能内嵌不跳转、能扫码不填表单
- **支付方式匹配市场**：海外 Stripe/Paddle（Paddle 兼代缴税务）；国内个人码起步、量大上商户
- **自动交付**：付款→交付无人值守（自动开权限/发卡/邮件）。凌晨 3 点的订单也要即时满足——**你的收入不该有营业时间**
- 自己每周走一遍全流程（付款到收到货），计时并记录每步流失点——这是转化审计

## 一人销售：对话式成交

对高客单（服务包/咨询/SaaS 大单），落地页只负责过滤意向，成交在对话里。一人销售的三个动作：

1. **诊断先于推销**：先问对方现状和目标（ch04 五问法的销售版），诊断清楚了方案是显然的
2. **报价即锚定**：从三档的最高价值档说起（不是坑人，是给对话一个参照系），然后按诊断结果推荐合适档
3. **异议 = 信息的缺口**："太贵了"的真相通常是"没看到对应的价值"→ 回到价值锚（ch07）；"我再想想"→ 问"具体是哪一点还在犹豫？"（不追单，追信息）

**速度是被低估的成交变量**：咨询回复的响应时间每缩短一档（24h→1h→5min），成交率显著上升——一人公司用自动化（ch12）保住响应速度，用人格保住温度。

## 基准与检验

转化诊断的三个常规检查（每周 30 分钟）：

- 漏斗各级转化率 vs 基准（访问→注册→付费）——断在哪一级补哪级
- 支付页放弃率（走完流程倒在付款，通常是信任/摩擦问题）
- 新老流量转化对比（熟人转化异常高=流量太窄）

## 坑与证伪

| 坑 | 核查 |
|---|---|
| A/B 测试一切 | 低流量下 A/B 是噪音放大器。<1000 转化/月时用定性访谈+大改动（整页重构）代替小改动测试 |
| 转化率崇拜 | 转化率×客单价=收入；99% 转化×客单 0=0。先保定价再优化转化 |
| 弹窗轰炸 | 首屏 3 秒弹窗流失>收益；退出意图位置是底线 |
| "注册"类 CTA | 动词+结果稳定优于抽象动词——把用户点击后的收益写在按钮上 |
| 自动化回复高冷 | 自动化保速度，但首次咨询回复若让人明显感觉是机器人，信任折损。混排：机器人过滤+人格收尾 |

## 小结

- 双口径基准：6.6%（含表单）/2.35%（均值）；访问→付费 1-3% 健康；要卡试用 30% 远胜 freemium 8%
- 七段落地页 + 信任四来源（公开构建/案例/人格/风险逆转）
- 支付交付无人值守；每周自走一遍全流程做转化审计
- 一人销售：诊断先于推销、报价即锚、异议是信息缺口、响应速度是隐形变量
